## Why teams still upload PDF agendas to ChatGPT

Registration vendors ship attendee MCP. Program chairs still export spreadsheets because abstract review, speaker readiness, and agenda changes live outside the registration record.

- Program teams export agendas for every AI experiment — data is stale before the prompt finishes.
- Registration MCP covers attendees; abstract review and speaker readiness stay siloed on spreadsheets.
- Generic ChatGPT uploads leak program data without role-based access or audit logs.
- Marketing and program ops maintain duplicate exports — Advocacy and agents should read one graph.
- Enterprise stacks need composable MCP layers — registration plus program, not one walled dataset.

## Frequently asked questions

Event MCP on Sessionboard — live for enabled organizations.

Is Event MCP available today?▼

Yes. The Sessionboard MCP server is live for enabled organizations. Connect via OAuth at mcp.sessionboard.com (EU: mcp-eu.sessionboard.com). Contact your account manager to enable MCP access on your org and API token.

What is Event MCP?▼

Model Context Protocol connecting AI assistants to live speaker, session, abstract, and review data in Sessionboard — not attendee registration records.

Does this replace RainFocus or Cvent MCP?▼

No — registration MCP and program MCP are complementary layers on a composable stack. Most enterprises run both.

Which AI tools are supported?▼

Claude Desktop, Claude Code, ChatGPT, and Microsoft Copilot via OAuth — see the MCP setup guide in API docs.

How many MCP tools are available?▼

27 tools — search and analytics, session and contact reads, and manage\_\* operations for sessions, contacts, agenda drafts, dashboards, and reports.

How does Advocacy fit?▼

Advocacy fires from the same acceptance graph agents read — consistent session and speaker state for marketing and ops.

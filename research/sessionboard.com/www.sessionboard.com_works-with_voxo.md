## What Sessionboard delivers natively

Keep VOXO mid-contract when you need to — Sessionboard owns call for papers, speaker operations, and content marketing on the program graph.

## VOXO — their lane

- **Branded minute-one summary pages**
One- and two-page session summaries with takeaways and LinkedIn share — when VOXO stays primary for that format.

- **Embeddable content hub**
Filterable hub of session summaries for event apps — VOXO-hosted UX during coexistence.

- **RTMP capture workflow**
Stage audio via RTMP into VOXO's pipeline when AV is locked to their URLs this season.


## Sessionboard — built in

- **Program graph and speaker CRM**
Call for papers (CFP), review, speaker portal, and agenda — authoritative session metadata for any capture path.

- **Branded session, event, and daily reports**
Branded session summaries, event reports, and daily debriefs for attendees and admins — in Attendee Hub and Create on your event brand, with or without VOXO in the stack.

- **Native transcription and Attendee Hub**
Live Transcribe, Media Library, replays, and AI summaries when you consolidate off VOXO — no parallel upload project.

- **Public API write-back**
write:transcriptions, write:media, write:sessions — ingest VOXO output while Sessionboard stays system of record. Documented at apidocs.sessionboard.com.

- **Clips, Create, and Advocacy**
Quote library, content generation, and tracked peer shares from the session record — not re-keyed from VOXO exports.


## How the data flows

Program and session data live in Sessionboard — with optional sync to and from VOXO.

- Sessionboard holds CFP, review, speakers, and published agenda — the metadata every capture path should attach to.
- Optional VOXO path — stream RTMP to VOXO for their summary templates during an active contract.
- Public API — write VOXO transcripts, recordings, and media artifacts to Sessionboard sessions (write:transcriptions, write:media).
- Attendee Hub, credits, and Advocacy read from Sessionboard — one attendee experience even when VOXO captures audio.
- Consolidation path — move capture to Sessionboard Live Transcribe; retire VOXO when contract allows. See compare page.

**Integration status:** Native Sessionboard transcription and Attendee Hub require no VOXO contract. Public API write scopes support coexistence when marketing keeps VOXO mid-cycle. Full API reference: apidocs.sessionboard.com — media guide covers transcription and recording upload.

## Native first — add their tool only if you must

Sessionboard already includes transcription, attendee experiences, and content marketing. A separate subscription makes sense only in narrow cases.

#### Keep VOXO only when

- Marketing already committed to VOXO enterprise contracts and summary template branding for this season only
- AV workflow is locked to VOXO RTMP URLs and cannot change mid-contract
- Legal requires VOXO as capture vendor while program ops migrate to Sessionboard

#### Sessionboard alone — usually the answer

- Evaluating VOXO for the first time — start with Sessionboard vs VOXO compare page
- CFP, review, and speakers already run on Sessionboard — transcription should start from that graph
- You want branded session summaries, event reports, and daily debriefs without a second summary vendor
- You want Attendee Hub with live transcripts, replays, and AI chat without embedding a third-party hub
- Clips, Create, and Advocacy should fire from acceptance and agenda publish on one platform
- Budget cycles favor one program plus content platform over summary SaaS plus program SaaS

## Frequently asked questions

How Sessionboard works beside VOXO.

Is Sessionboard partnered with VOXO?▼

No. This page documents coexistence — how to keep VOXO mid-contract while Sessionboard owns program data. For displacement evaluation, see Sessionboard vs VOXO.

Can we use VOXO and still keep Sessionboard as system of record?▼

Yes. Public API write scopes let you sync transcriptions, recordings, and media back to Sessionboard sessions. Attendee Hub and credits stay authoritative in Sessionboard.

How does audio capture work?▼

Sessionboard captures live via Live Transcribe or batch ingest. VOXO RTMP is optional during coexistence — not required for transcription long term.

What API endpoints do we use?▼

write:transcriptions, write:media, and session recordings — see apidocs.sessionboard.com/guides/uploading-media-and-transcriptions.

VOXO integrates with RainFocus — where does Sessionboard fit?▼

Sessionboard is the program layer beside registration. Speaker and session truth lives here.

When should we consolidate to Sessionboard only?▼

When the VOXO contract ends — native Content Marketing already covers branded session summaries, event and daily reports, Live Transcribe, Attendee Hub, and clips on the graph you already run.

Where VOXO stops, and where program teams keep going with Sessionboard.

## VOXO — where it ends

- **Branded minute-one summary pages**
One- and two-page session summaries with takeaways and LinkedIn share — a marketing deliverable format.

- **Embeddable content hub**
Filterable hub of session summaries for event apps — when you want VOXO's hosted UX.

- **RTMP capture workflow**
Stage audio via RTMP into VOXO's pipeline — Sessionboard also captures live via Live Transcribe and batch ingest.


### The narrow case

- Marketing already committed to VOXO enterprise contracts and summary template branding for this season only
- AV workflow is locked to VOXO RTMP URLs and cannot change mid-contract

The way forward

## Sessionboard — program, CRM & content

- **Branded session, event, and daily reports**
Branded session summaries, full event reports, and daily debriefs for attendees and admins — customer-branded in Attendee Hub and Create, not a separate summary subscription.

- **Live transcription and Media Library**
Live Transcribe capture, batch transcription with diarization, AI summaries, quote extraction, and searchable org library — on the session graph.

- **Attendee Hub**
Branded attendee microsite with live stage, replays, transcripts, reactions, event reports, and AI chat — native delivery without a third-party hub.

- **Clips, Create, and Remix**
AI clip suggestions, branded clip render, multi-format content generation, and bulk metadata optimization from transcript data.

- **Public API write-back**
write:transcriptions, write:media, and session recordings — one program record when VOXO captures audio. See apidocs.sessionboard.com.


### When Sessionboard wins

- Call for papers (CFP), review, and speakers already run on Sessionboard — transcription should start from that graph
- You want branded session summaries, event reports, and daily debriefs for attendees and admins without a second summary vendor
- You want Attendee Hub with live transcripts, replays, reactions, and AI chat without embedding a third-party hub
- Clips, quote cards, and Create outputs should reuse abstract text and learning objectives already on the session
- Peer promotion via Advocacy should fire from acceptance and agenda publish — not a separate content subscription
- Medical or scientific societies need learning-object packaging from the transcript pipeline on Sessionboard
- Budget cycles favor one program plus content platform over summary SaaS plus program SaaS

## Frequently asked questions

Evaluating Sessionboard against VOXO for the program layer — not a forced rip-and-replace.

Does Sessionboard replace VOXO?▼

For most teams — yes. Live transcription, branded session summaries, event and daily reports, Attendee Hub, clips, and Advocacy are native on Content Marketing. VOXO is optional mid-contract when you need their hosted summary hub UX specifically.

Can we use VOXO and still keep Sessionboard as system of record?▼

Yes. The public API lets you write transcriptions, recordings, and media back to Sessionboard sessions so program, credits, and Attendee Hub stay authoritative.

How does audio capture work?▼

Sessionboard captures live via Live Transcribe or ingests recordings into Media Library with batch transcription. VOXO's RTMP path is optional — not required for transcription.

What about attendee captions and accessibility?▼

Sessionboard transcription feeds Attendee Hub replays, captions, and searchable transcripts natively. VOXO summaries are a marketing format — not a substitute for accessibility workflow.

VOXO integrates with RainFocus — where does Sessionboard fit?▼

Sessionboard is the program layer beside registration. Speaker and session truth lives here; transcription and attendee content can stay here too.

When should we pay for both?▼

Only when marketing has a committed VOXO contract and you need public API sync this cycle. Default evaluation should start with native Content Marketing on Sessionboard.

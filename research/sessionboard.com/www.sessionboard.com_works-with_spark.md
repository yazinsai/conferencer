## What Sessionboard delivers natively

Keep Spark mid-contract when you need to — Sessionboard owns call for papers, speaker operations, and content marketing on the program graph.

## Spark — their lane

- **Generic AI task library**
Multi-model prompts for marketing copy not tied to a live event database.

- **Agent Studio experiments**
No-code chains for marketers exploring AI workflows outside program systems.

- **Horizontal productivity**
Useful when AI literacy is the buy — not when program automation is the buy.


## Sessionboard — built in

- **Event-state-driven Create and Studio**
Articles, carousels, quote cards, and video projects from transcripts and session metadata — no prompt paste.

- **Remix and program AI**
Bulk metadata optimization and Enterprise AI agents for review matching, triage, and agenda assistance on in-platform data.

- **Transcription-to-content pipeline**
Live and batch transcription feeds quotes, clips, and Create inputs on the Media Library graph.

- **Advocacy peer marketing**
Tracked advocacy links, LinkedIn publish, and AI share copy when speakers and sponsors promote sessions they are in.


## How the data flows

Program and session data live in Sessionboard — with optional sync to and from Spark.

- Session accepted in Sessionboard — Create and automated comms use speaker name, abstract, and track without export.
- Agenda published — Remix optimizes titles and descriptions; Attendee Hub and embeds update from live state.
- Transcription completes — quote library and Create pull standout lines and chapters from Media Library.
- Optional Spark path — copy program context into Spark tasks for generic marketing experiments Spark handles better.
- Advocacy campaigns assign advocates tracked links; analytics tie shares to registration — not available in Spark.

**Integration status:** Sessionboard Create, Remix, and Advocacy require no Spark subscription. Spark ↔ Sessionboard Apps connector is planned for teams that keep both; today program context exports manually if marketing insists on Spark for non-program tasks.

## Native first — add their tool only if you must

Sessionboard already includes transcription, attendee experiences, and content marketing. A separate subscription makes sense only in narrow cases.

#### Keep Spark only when

- Marketing already pays for Spark seats and uses Agent Studio for non-program content experiments
- Comms team wants a sandbox separate from production program data for brainstorm drafts

#### Sessionboard alone — usually the answer

- AI outputs should trigger from acceptance, agenda publish, and transcription events — not manual exports
- Transcription, clips, Attendee Hub, Create, and Advocacy should share one session graph
- Per-seat AI tool sprawl does not fit association economics — Content Marketing bundles capture and repurposing natively
- Enterprise AI agents on program workflow (review, triage, agenda) are the strategic buy over generic task lists
- Peer promotion with registration attribution requires Advocacy — not Spark

## Frequently asked questions

How Sessionboard works beside Spark.

Does Sessionboard replace Spark?▼

For program and session content — yes. Create, Remix, transcription, and Advocacy are native. Spark remains optional for generic marketing AI experiments outside program data.

How is Agent Studio different from Sessionboard AI?▼

Spark chains generic marketer actions. Sessionboard Enterprise AI targets program workflows — reviewer matching, triage, agenda assistance — on data inside your event.

Where do transcription and attendee experiences fit?▼

Native on Sessionboard — Media Library, Attendee Hub, and companion APIs. Spark does not capture live sessions or deliver attendee replays.

Can we write partner AI output back to Sessionboard?▼

If a partner produces transcripts or media, public API supports write:transcriptions and write:media on sessions. Native capture avoids that step.

Can we start with Spark and add Sessionboard later?▼

Most teams hit program pain first — spreadsheets, email committees, re-keyed exports. Sessionboard is usually the entry point; Spark is additive for marketing AI literacy.

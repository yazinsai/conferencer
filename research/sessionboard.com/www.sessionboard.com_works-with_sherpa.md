## Quick answer

Sherpa builds white-label event mobile apps for associations and enterprises. Sessionboard holds the authoritative session and speaker graph — agenda publish, last-minute changes, and speaker materials flow to Sherpa apps Sherpa deploys for your event.

## Sound like your team?

Match your role to the job Sessionboard solves — program ops, content reuse, or marketing attribution.

### Floor plan / ops lead

Sherpa builds from program exports — Sessionboard should be authoritative for sessions, speakers, rooms, and times.

### Program manager

Agenda changes re-keyed into Sherpa — publish from Sessionboard and sync, not spreadsheet round-trips.

### Speaker operations

Speaker data duplicated into floor plan tool — one faculty record feeds Sherpa builds via API or export.

### Executive buyer

Rip-and-replace Sherpa is rare — you need program depth on Sessionboard while floor planning stays put.

## What Sessionboard delivers natively

Keep Sherpa mid-contract when you need to — Sessionboard owns call for papers, speaker operations, and content marketing on the program graph.

## Sherpa — their lane

- **White-label event apps**
Branded iOS/Android apps per client event or portfolio.

- **App delivery and support**
Sherpa owns app store deployment and attendee-facing mobile UX.

- **Customer app portfolio**
Multi-event apps for associations with recurring meetings.


## Sessionboard — built in

- **Authoritative session graph**
Agenda, speakers, rooms, and last-minute changes from program team.

- **Speaker materials pipeline**
Bios, headshots, and slides collected before publish to app feeds.

- **Live content and Attendee Hub**
Transcripts, replays, and session recaps — optional native delivery beside Sherpa app.


## How the data flows

Program and session data live in Sessionboard — with optional sync to and from Sherpa.

- Program team publishes agenda in Sessionboard — sessions, speakers, rooms, times.
- Integration or export feeds Sherpa app build — Sherpa owns mobile shell and push notifications.
- Last-minute session changes originate in Sessionboard — reduce stale schedule risk in app.
- Optional: Attendee Hub and transcription links deep-link from Sherpa app to Sessionboard-hosted content.

**Integration status:** Sherpa owns the mobile app relationship; Sessionboard supplies the authoritative program graph via API or export.

## Native first — add their tool only if you must

Sessionboard already includes transcription, attendee experiences, and content marketing. A separate subscription makes sense only in narrow cases.

#### Keep Sherpa only when

- Enterprise mandate for Sherpa mobile apps already deployed
- Multi-event portfolio on Sherpa with dedicated app team

#### Sessionboard alone — usually the answer

- Program data still re-keyed from Excel into Sherpa builds
- Need transcription and on-demand library beyond schedule browsing
- Speaker CRM should be source of truth before app publish

How Sessionboard works beside Sherpa.

Who owns the mobile app?▼

Sherpa — Sessionboard does not replace attendee mobile apps; it feeds program data.

Does Sessionboard replace Sherpa?▼

No — coexist. Sessionboard replaces spreadsheet program ops that feed Sherpa.

What data syncs?▼

Can attendees watch replays in Sherpa?▼

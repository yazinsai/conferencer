## What Sessionboard delivers natively

Keep Gleanin mid-contract when you need to — Sessionboard owns call for papers, speaker operations, and content marketing on the program graph.

## Gleanin — their lane

- **Social amplification campaigns**
Exhibitor and attendee sharing UX, gamification, and leaderboard mechanics Gleanin is known for at ISO-scale shows.

- **Amplification UI for marketing teams**
Campaign surfaces marketing can run without rebuilding from spreadsheets each season.

- **Portfolio-standard amplification**
Enterprise ISOs that standardized on Gleanin across a show portfolio.


## Sessionboard — built in

- **Program graph from CFP to publish**
Abstracts, multi-round review, speaker portal, agenda, and registration surfaces — the metadata worth sharing.

- **Native Product Advocacy**
Milestone prompts from speaker acceptance, personalized share pages, and tracked links — not a separate advocacy login.

- **Share → registration attribution**
Measure advocate, channel, and conversion on registrations Sessionboard already owns.

- **Gleanin session sync**
Native connector syncs session and speaker state to Gleanin — Last Sync (Gleanin) on the session record.


## How the data flows

Program and session data live in Sessionboard — with optional sync to and from Gleanin.

- Program team runs CFP, review, and speaker readiness in Sessionboard — authoritative session titles, bios, and times.
- Agenda publish triggers Gleanin sync — sessions and speakers stay aligned without re-keying into amplification tools.
- Gleanin runs social campaigns, exhibitor sharing, and gamification for teams standardized on that UX.
- Sessionboard Advocacy fires from program milestones — acceptance, agenda live, early-bird — with assets built from the same graph.
- Registration attribution closes on Sessionboard — which advocate and channel drove the signup, including post-share watch paths when content lives on Attendee Hub.

**Integration status:** Native Gleanin integration ships in Sessionboard — session sync via Integration\_Gleanin\_\* models and continuous sync jobs. Speaker portal can surface Gleanin advocate links where configured. Sessionboard Advocacy is available natively for teams that want attribution without a second amplification contract.

## Native first — add their tool only if you must

Sessionboard already includes transcription, attendee experiences, and content marketing. A separate subscription makes sense only in narrow cases.

#### Keep Gleanin only when

- Enterprise ISO mandate to keep Gleanin across a multi-show portfolio
- Marketing team owns Gleanin campaigns separately from program operations
- You want Gleanin gamification UX plus Sessionboard program depth and sync

#### Sessionboard alone — usually the answer

- Amplification should start at speaker acceptance — not after a separate import
- You need share-to-registration attribution Gleanin campaigns cannot close alone
- Sponsor amplification inventory should tie to session and exhibitor records you already manage
- Per-seat advocacy pricing does not fit association economics
- Transcription, Attendee Hub, and post-event content should live on the same graph as advocacy

## Frequently asked questions

How Sessionboard works beside Gleanin.

Does Sessionboard replace Gleanin?▼

Not by default — many ISOs coexist. Sessionboard adds program depth, native Advocacy, and registration attribution. Gleanin remains the amplification UI when marketing is standardized on it.

Is there a native Gleanin integration?▼

Yes — Sessionboard syncs session and speaker data to Gleanin and tracks last sync on sessions. Configure Integration Gleanin in your event settings.

Can we measure registrations from peer shares?▼

Sessionboard Advocacy attributes shares to registrations (and content views when using Attendee Hub). Use this to complement Gleanin campaign metrics.

What about Snöball or InGo?▼

Same coexistence pattern — see Sessionboard + Snöball and Sessionboard + InGo works-with guides.

We only need abstract management — do we need Gleanin?▼

No. Add peer-to-peer marketing when amplification becomes a priority — it extends the program graph you already run.

## What Sessionboard delivers natively

Keep WordPress mid-contract when you need to — Sessionboard owns call for papers, speaker operations, and content marketing on the program graph.

## WordPress — their lane

- **Marketing website CMS**
WordPress themes, pages, blogs, and SEO on your domain.

- **Content marketing publishing**
Editorial workflow and plugins your web team already operates.

- **Public site branding**
Design system and navigation visitors expect from your association or event brand.


## Sessionboard — built in

- **Authoritative program graph**
Sessions, speakers, rooms, times, and materials from program team workflow.

- **Session and speaker embeds**
Live widgets for agenda grids, speaker lists, and session detail — update when program changes.

- **Full program depth**
CFP, review, transcription, Attendee Hub, and advocacy beyond what embeds alone provide.


## How the data flows

Program and session data live in Sessionboard — with optional sync to and from WordPress.

- Program team publishes agenda and speakers in Sessionboard.
- WordPress pages embed Sessionboard session/speaker blocks — live data, no re-keying.
- Last-minute session changes originate in Sessionboard — embeds refresh for attendees browsing the marketing site.
- Optional — Attendee Hub and transcription links from WordPress session pages for on-demand content.

**Integration status:** Sessionboard session and speaker embeds work on WordPress via iframe or script embed — program graph is system of record. EventSites (Sessionboard native sites) available for teams replacing WordPress over time.

## Native first — add their tool only if you must

Sessionboard already includes transcription, attendee experiences, and content marketing. A separate subscription makes sense only in narrow cases.

#### Keep WordPress only when

- Marketing mandate to keep WordPress as public site CMS
- Program team already runs CFP and speakers in Sessionboard or plans to migrate
- Need live agenda on marketing site without duplicate CMS entry

#### Sessionboard alone — usually the answer

- WordPress agenda pages are manually updated from Excel after every chair change
- Need abstract review and speaker portal — not just public session display
- Post-meeting content and advocacy should live on the same graph as embeds

## Frequently asked questions

How Sessionboard works beside WordPress.

Does Sessionboard replace WordPress?▼

No for marketing CMS — Sessionboard embeds program data into WordPress. EventSites is the native alternative when teams want Sessionboard-hosted event websites.

What can we embed?▼

Session lists, speaker directories, and session detail — confirm embed options with Sessionboard sales.

Do embeds update automatically?▼

Yes — when program data changes in Sessionboard, embeds reflect authoritative session and speaker state.

Can we run abstract review in WordPress?▼

No — CFP and committee review run in Sessionboard; WordPress displays published program output.

What about registration?▼

Registration can stay on Cvent, CDS, or another vendor — embeds focus on program display.

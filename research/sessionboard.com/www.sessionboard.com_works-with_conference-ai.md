## What Sessionboard delivers natively

## Conference AI — their lane

- **Cross-event content library UX**
Portfolio-wide searchable library when Conference AI is your marketing system's front door.

- **Post-event clip and recap workflows**
AI packaging of recordings into marketing assets — overlapping Sessionboard Create and Media Library.

- **Attendee recap surfaces**
Personalized highlight experiences in Conference AI's app layer — Sessionboard Attendee Hub covers this natively.


## Sessionboard — built in

- **Program graph from CFP to publish**
Abstracts, multi-round review, speaker portal, and agenda state — the authoritative metadata transcription should attach to.

- **Live and batch transcription**
Live Transcribe capture, batch ingest, diarization, summaries, and quote library tied to sessions — not a separate upload project.

- **Attendee Hub and engagement**
Branded attendee microsite with live transcripts, replays, reactions, AI chat, event reports, and podcasts from session data.

- **Public API write-back**
write:transcriptions, write:media, and session recordings endpoints — keep Sessionboard as system of record if Conference AI captures audio.


## How the data flows

Program and session data live in Sessionboard — with optional sync to and from Conference AI.

- Default — Sessionboard captures or ingests audio; transcription pipeline produces fragments, summaries, quotes, and clips on the session record.
- Attendee Hub publishes live and replay experiences from that record — transcripts, recaps, and AI chat without Conference AI.
- Create and Studio turn transcripts into articles, carousels, and social assets using speaker and abstract metadata already in Sessionboard.
- Optional Conference AI path — upload or stream to Conference AI; sync transcripts and media back via public API so credits, library, and Attendee Hub stay unified.
- Advocacy generates tracked advocacy links from session and quote artifacts — peer marketing from the same graph.

**Integration status:** Native transcription and Attendee Hub ship on Sessionboard Content Marketing — no Conference AI required. Public API supports coexistence (write:transcriptions, write:media, session recordings). Native Conference AI connector is on the Apps roadmap for teams that keep both.

## Native first — add their tool only if you must

Sessionboard already includes transcription, attendee experiences, and content marketing. A separate subscription makes sense only in narrow cases.

#### Keep Conference AI only when

- Marketing has an active Conference AI enterprise contract for cross-event library UX this fiscal year
- Legal or procurement already approved Conference AI for AI processing and cannot switch mid-cycle

#### Sessionboard alone — usually the answer

- Abstract and speaker workflow already lives on Sessionboard — transcription should start there, not after export
- You want Attendee Hub, captions, clips, and on-demand library on one platform with metered transcription hours
- Medical or scientific societies need learning-object export from transcripts on the session record
- Create, Remix, and Advocacy should trigger from acceptance and live session events automatically
- Another flat SaaS subscription for unlimited AI sessions does not fit association budget cycles
- Public API is available if a partner captures audio — but native capture avoids the integration tax entirely

## Frequently asked questions

How Sessionboard works beside Conference AI.

Does Sessionboard replace Conference AI?▼

For most program teams — yes. Live transcription, Attendee Hub, clips, Create, and Advocacy and Dispatch are native. Conference AI is optional when marketing standardized on their library UX.

Does Sessionboard transcribe live sessions?▼

Yes — Live Transcribe capture from the Live Transcribe Console, plus batch ingest with diarization, summaries, and quote extraction on Content Marketing. Metered by audio hour.

How do we coexist with Conference AI?▼

Use public API to write transcriptions, recordings, and media artifacts back to Sessionboard sessions. Program, Attendee Hub, and credits stay authoritative in Sessionboard.

What about VOXO or Spark?▼

Same pattern — native first, partner optional, public API for write-back. See works-with pages.

We only need abstract management — do we need Conference AI?▼

No. Add Content Marketing when transcription and attendee content become priorities — it extends the graph you already run, not a parallel system.

How does pricing compare?▼

Conference AI publishes flat plans. Sessionboard bundles Content Marketing with metered transcription — compare total cost for your session count and advocate campaigns.

## What Sessionboard delivers natively

Keep Wordly mid-contract when you need to — Sessionboard owns call for papers, speaker operations, and content marketing on the program graph.

## Wordly — their lane

- **Live multilingual translation**
Real-time translation into dozens of languages — translated audio and subtitles when Wordly stays primary for global audiences.

- **QR attendee caption UX**
Attendees join via QR or URL on personal devices for live translation and captions — no download required.

- **Hybrid and Teams capture**
In-room AV, Zoom, and Microsoft Teams paths when AV is locked to Wordly this season.


## Sessionboard — built in

- **Program graph and speaker CRM**
Call for papers (CFP), review, speaker portal, and agenda — authoritative session metadata for any capture path.

- **Native transcription and Attendee Hub**
Live Transcribe, Media Library, replays, same-language captions, and AI summaries when you consolidate off Wordly.

- **Branded session, event, and daily reports**
Branded session summaries, event reports, and daily debriefs in Attendee Hub and Create on your event brand.

- **Public API write-back**
write:transcriptions, write:media, write:sessions — ingest Wordly output while Sessionboard stays system of record. Documented at apidocs.sessionboard.com.

- **Clips, Create, and Advocacy**
Quote library, content generation, and tracked peer shares from the session record — not re-keyed from Wordly exports.


## How the data flows

Program and session data live in Sessionboard — with optional sync to and from Wordly.

- Sessionboard holds CFP, review, speakers, and published agenda — the metadata every capture path should attach to.
- Optional Wordly path — route stage or virtual audio to Wordly for multilingual translation during an active contract.
- Public API — write Wordly transcripts, recordings, and media artifacts to Sessionboard sessions (write:transcriptions, write:media).
- Attendee Hub, credits, and Advocacy read from Sessionboard — one attendee experience even when Wordly handles translation.
- Consolidation path — move capture to Sessionboard Live Transcribe when multilingual requirements allow; retire Wordly when contract ends. See compare page.

**Integration status:** Native Sessionboard transcription and Attendee Hub require no Wordly contract. Public API write scopes support coexistence when procurement keeps Wordly mid-cycle. Full API reference: apidocs.sessionboard.com — media guide covers transcription and recording upload.

## Native first — add their tool only if you must

Sessionboard already includes transcription, attendee experiences, and content marketing. A separate subscription makes sense only in narrow cases.

#### Keep Wordly only when

- Procurement already committed to Wordly for multilingual live translation this fiscal year
- Sessions require simultaneous translation into many languages — beyond same-language captioning
- AV workflow is locked to Wordly capture and room monitors and cannot change mid-contract

#### Sessionboard alone — usually the answer

- Evaluating Wordly for the first time — start with Sessionboard vs Wordly compare page
- CFP, review, and speakers already run on Sessionboard — transcription should start from that graph
- Primary need is same-language captions, Attendee Hub, and post-event content — not translation-only SaaS
- Clips, Create, and Advocacy should fire from acceptance and agenda publish on one platform
- Budget cycles favor one program plus content platform over translation SaaS plus program SaaS

## Frequently asked questions

How Sessionboard works beside Wordly.

Is Sessionboard partnered with Wordly?▼

No. This page documents coexistence — how to keep Wordly mid-contract while Sessionboard owns program data. For displacement evaluation, see Sessionboard vs Wordly.

Can we use Wordly and still keep Sessionboard as system of record?▼

Yes. Public API write scopes let you sync transcriptions, recordings, and media back to Sessionboard sessions. Attendee Hub and credits stay authoritative in Sessionboard.

What is the difference between Wordly and Sessionboard captions?▼

Wordly specializes in live multilingual translation and QR attendee access. Sessionboard delivers same-language Live Transcribe, Attendee Hub, branded reports, and content marketing on the program graph.

What API endpoints do we use?▼

write:transcriptions, write:media, and session recordings — see apidocs.sessionboard.com/guides/uploading-media-and-transcriptions.

We use Wordly with MPI or association events — where does Sessionboard fit?▼

Sessionboard is the program and speaker layer beside translation. Session metadata, credits, and post-event content reuse live here even when Wordly handles live translation.

When should we consolidate to Sessionboard only?▼

When multilingual translation is no longer required every session — native Content Marketing covers Live Transcribe, Attendee Hub, branded reports, and clips on the graph you already run.

# Download headshots

There are three ways you can download headshots that have been collected within the standard Headshot field provided by Sessionboard.

![Download headshots](https://learn.sessionboard.com/images/kb/2596fb39-image-png-Feb-09-2026-10-07-33-6867-PM.png)

## OPTION A: Download Headshot(s) as a Zip File

[Section titled “OPTION A: Download Headshot(s) as a Zip File”](https://learn.sessionboard.com/faq/how-to-download-headshots#option-a-download-headshots-as-a-zip-file)

![OPTION A: Download Headshot as a Zip File](https://learn.sessionboard.com/images/kb/0394998e-image-png-Feb-09-2026-10-07-50-4907-PM.png)

1. Within the Speaker/Contacts module, select the speaker/contact whose headshot you’d like to download using the checkbox next to their name.
2. At the top of your page, select the button More > Download Headshots.
3. A zip file will be downloaded to your device with the contact’s first and last name appended in the name of each file.

![A zip file will be downloaded to your device with the contact’s first and last name appended in the name](https://learn.sessionboard.com/images/kb/853a5c7d-image-png-Feb-09-2026-10-08-26-3332-PM.png)

## OPTION B: Download Individual File

[Section titled “OPTION B: Download Individual File”](https://learn.sessionboard.com/faq/how-to-download-headshots#option-b-download-individual-file)

1. Within the Speakers module, ensure that the field Headshot is visible within your dashboard view.
2. 👉🏽 Learn how to add the headshot field to your view.
3. Locate the speaker you would like to download a headshot for, and select the file within the Headshot field. This will open a pop-up window that previews the image uploaded. ​

![OPTION B: Download Individual File](https://learn.sessionboard.com/images/kb/afd226ed-image-png-Feb-09-2026-10-08-58-8078-PM.png)

3. It’ll open the image in a new browser tab to view and download.

## OPTION C: Export Spreadsheet with File URL

[Section titled “OPTION C: Export Spreadsheet with File URL”](https://learn.sessionboard.com/faq/how-to-download-headshots#option-c-export-spreadsheet-with-file-url)

1. Within the Speakers module, ensure that the field Headshot is visible within your dashboard view.
2. 👉🏽 Learn how to add the headshot field to your view.
3. Once your dashboard view has been updated, export your view as either a CSV or XLSX file.
4. 👉🏽 Learn how to export data.

![OPTION C: Export Spreadsheet with File URL](https://learn.sessionboard.com/images/kb/acee6d57-image-png-Feb-09-2026-10-10-09-3380-PM.png)

![Learn how to export data](https://learn.sessionboard.com/images/kb/d1156c62-Screenshot-2024-04-10-at-11_04_46-AM-1.png)

The exported file will include the hosted URL link for each file within Sessionboard.

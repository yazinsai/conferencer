# Webhooks

A webhook (web callback or HTTP push) lets the Sessionboard API deliver real-time information to your integrated applications — you get an immediate notification when data changes, rather than polling for it.

## Implement webhooks

[Section titled “Implement webhooks”](https://learn.sessionboard.com/integrations/webhooks#implement-webhooks)

1. Confirm you have the necessary prerequisites.
2. Create a webhook.
3. Test the webhook.

For full setup details, request/response schemas, and event types, see the [developer documentation](https://apidocs.sessionboard.com/introduction).

# Agenda & speaker embeds

Embeds let you export a feed of your agenda, sessions, and speakers to place in your app or website. The feed refreshes automatically — no manual sync or push required. You can output as styled HTML, basic HTML, JSON, XML, or iCal.

## Embed types

[Section titled “Embed types”](https://learn.sessionboard.com/sessions/embeds#embed-types)

Schedule itinerary

Searchable sessions with multiple filters; prominent speaker headshots and bios.

Speaker gallery

Speakers alphabetically by last name, with headshots and details.

Agenda

Approved sessions in a grid by location and time.

Session list

Sessions with speakers, filterable by format, language, tag, track, location.

Speaker list

Speakers with their sessions and info.

## Create an embed

[Section titled “Create an embed”](https://learn.sessionboard.com/sessions/embeds#create-an-embed)

Open Embeds

In the **Deliver** module, select **Embeds**.

Add an embed

Click **Add Embed**.

Choose a format

- **Embed Styled HTML** — one line of JavaScript for an interactive agenda/session/speaker list
- **Embed HTML** — HTML output for developers to style to your site theme
- **JSON / XML** — expanded properties for apps or databases
- **iCal** — a calendar link showing all approved sessions as events

Style & filter

(Styled/HTML only) Set display options, colors, and optional custom CSS, then apply filters such as specific tracks or statuses.

Select fields

Choose fields for the Agenda, Speaker, and Session cards. Grey fields are required; blue fields are preselected and customizable.

Save

Click **Save** to retrieve the embed code, and **Preview** to open it in a new window. Share the code with your web team.

## Updates & editing

[Section titled “Updates & editing”](https://learn.sessionboard.com/sessions/embeds#updates--editing)

Embeds auto-update every **60 minutes**. For faster updates, use **Embeds → ⋯ → Refresh Cache**. To edit, use **Embeds → ⋯ → Edit** — you can change styling and fields, but not the data type (create a new embed to change type). You may need to refresh the cache to see changes.

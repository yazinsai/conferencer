# Create custom reports

## Report types

[Section titled “Report types”](https://learn.sessionboard.com/reporting/custom-reports#report-types)

- **Session reports** — combine session and contact data (sessions on the Y-axis).
- **Contact reports** — combine session, contact, and sponsor/exhibitor data (contacts on the Y-axis).
- **Group reports** — combine session, contact, and sponsor/exhibitor data (groups on the Y-axis).
- **Evaluation plan reports** — evaluator details and grades.

## Canned reports

[Section titled “Canned reports”](https://learn.sessionboard.com/reporting/custom-reports#canned-reports)

Pre-built reports include _Sessions with Speaker Details_, _Sessions with Evaluation Ratings_, _Speakers with Session Details_, _Chairpersons/Moderators/Submitters with Session Details_, _Sponsors/Exhibitors with Contact and Session Details_, and evaluator/grade reports.

## Create a custom report

[Section titled “Create a custom report”](https://learn.sessionboard.com/reporting/custom-reports#create-a-custom-report)

Add a report

In the **Reports** module, click **Add Report** and choose a session, contact, or group report.

Configure

Set a **Report Name** (required) and description, and choose **Relationships** (e.g., session speakers, evaluation plans) — each becomes a column.

Choose fields

Pick fields (categorized as Sessions, People, or Groups). Drag to reorder within each category.

Filters & sorting

Filter by field — dropdown (is/is not), checkbox (is/is not checked), number/text (empty, not empty, contains, does not contain), file (empty/not empty). Enable **Must match all filters** to require every condition.

Review & run

Review the setup, then **Run Report** to generate an XLSX or CSV.

## Manage reports

[Section titled “Manage reports”](https://learn.sessionboard.com/reporting/custom-reports#manage-reports)

Use the gear icon on a report card to **Edit**, **Delete**, or **Duplicate** a report (duplicating saves time when building similar reports).

# Converting a session to a subsession

With subsessions, you have the ability to convert a pre-existing parent session into a subsession. Reverting a subsession to a parent session is just as easy!

❗️IMPORTANT NOTES❗️

- Admins can create up to 200 subsessions.
- The date and time of a subsession must fall within the date and time of the parent session.
- Integrations currently do not support subsessions.

1. Navigate to the Sessions module and determine the parent session that you would like to link another session to as a subsession.
2. Select the pencil to the left of the parent session to open the editing window and navigate to the “Subsessions” page.

![Converting a session to a subsession](https://learn.sessionboard.com/images/kb/8ff9a1b7-image-png-Feb-09-2026-08-26-58-8220-PM.png)

3. Select the button “Convert Sessions”.

![Select the button “Convert Sessions”](https://learn.sessionboard.com/images/kb/87b3d70d-image-png-Feb-09-2026-08-27-19-3397-PM.png)

4. From the list of existing parent sessions, select the session(s) that you would like to convert to a subsession. Once complete, click the button “Confirm” at the bottom of the pop-up window.

![From the list of existing parent sessions](https://learn.sessionboard.com/images/kb/ede12f86-image-png-Feb-09-2026-08-28-31-4720-PM.png)

5. From there, you will be taken to a confirmation page to review the parent session and subsession(s) selected. If all information is correct, click “Save” at the bottom of the window.
6. NOTE: Since subsessions must take place within the same date AND time as the parent session, the selected subsession(s) will take on the same date and time as the parent session when you click the “Save” button. You are able to adjust the time (still falling within the timeframe of the parent session) once the information has been saved.

![From there, you will be taken to a confirmation page to review the parent session and subsession(s) selected](https://learn.sessionboard.com/images/kb/2f52b5f1-image-png-Feb-09-2026-08-29-07-0435-PM.png)

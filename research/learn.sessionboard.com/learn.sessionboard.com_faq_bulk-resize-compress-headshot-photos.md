# Bulk resize headshot photos

## Resize Headshots (set dimensions)

[Section titled “Resize Headshots (set dimensions)”](https://learn.sessionboard.com/faq/bulk-resize-compress-headshot-photos#resize-headshots-set-dimensions)

![Resize Headshots](https://learn.sessionboard.com/images/kb/7f88db07-image-png-Feb-09-2026-09-49-35-8124-PM.png)

2. More → Resize Headshots

![More → Resize Headshots](https://learn.sessionboard.com/images/kb/0ddb6de7-image-png-Feb-09-2026-09-49-54-1228-PM.png)

3. Enter new dimensions to resize the selected headshots. You can specify both height and width, or just one value to scale proportionally. (Optional) Set a target filesize (KB).

![Enter new dimensions to resize the selected headshots](https://learn.sessionboard.com/images/kb/f4689ed2-image-png-Feb-17-2026-06-55-37-1371-PM.png)

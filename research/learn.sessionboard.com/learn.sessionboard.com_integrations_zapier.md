# Zapier

![Zapier logo](https://learn.sessionboard.com/logo/apps/zapier.png)

## Connect Sessionboard to Zapier

[Section titled “Connect Sessionboard to Zapier”](https://learn.sessionboard.com/integrations/zapier#connect-sessionboard-to-zapier)

Start a new Zap

In Zapier, click **Create → New Zap** and select **Sessionboard** as the trigger app.

Authenticate

Provide:

- **Connection name** — e.g., your event name
- **Region** — Europe (`appv2-eu.sessionboard.com`) or United States (`appv2.sessionboard.com`)
- **Application ID & Integration Key** — from **Settings → Integrations → Zapier → Get Access**
- **Organization API Key** — from **Organization Dashboard → Settings → [API Tokens](https://learn.sessionboard.com/integrations/api-tokens) → Create Token**

Choose a trigger

Contact, session, sponsor, and exhibitor triggers are available — e.g., _New Contact Created_, _Session Recently Updated_, _New Sponsor Created_, _Contact Recently Associated With Event_.

Add a find-record action

Add a Sessionboard action matching your trigger (e.g., **Find Contact**).

Connect an external app

Pick the destination app (e.g., Slack → Send Channel Message), map fields, and **Test**.

Publish

Name your Zap and click **Publish**.

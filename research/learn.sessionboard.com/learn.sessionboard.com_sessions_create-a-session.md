# Create a session

Sessions can be added to Sessionboard in two ways:

1. Through a [session submission form](https://learn.sessionboard.com/sessions/submission-forms)
2. Manually, as an admin (below)

## Create a session manually

[Section titled “Create a session manually”](https://learn.sessionboard.com/sessions/create-a-session#create-a-session-manually)

Open Submissions

Navigate to the **Sessions** module and click **Submissions**.

Add a session

Click the **Add Session** button in the top right.

Fill in the details

In the pop-up, complete the fields:

- **Details** — session details
- **Participants** — speakers, moderators, sponsors, exhibitors, or chairpersons

Save

Click **Add Session** at the bottom of the pop-up. **Title** and **Status** are required.

## Add data to custom fields

[Section titled “Add data to custom fields”](https://learn.sessionboard.com/sessions/create-a-session#add-data-to-custom-fields)

Create the session first

Create the session with at least a **Title** and **Status**.

Open the session profile

Select the pencil icon to the left of the session.

Locate custom fields

Scroll to the bottom of the page to find your custom fields, then add data.

Save

Save the session when you’re done.

# Add a moderator & chairperson

A moderator and chairperson are additional people contacts that can be created and linked to a session by an event admin. These contacts are not created by completing a session submission form. Below, are instructions on how to create both contact roles and link them to a session.

## How to create a moderator/chairperson

[Section titled “How to create a moderator/chairperson”](https://learn.sessionboard.com/contacts/add-a-moderator-chairperson#how-to-create-a-moderatorchairperson)

1. Within the “Contacts” module, specifically ‘All Contacts’, select the “Add Contact” button at the top right-hand corner of the screen.

![How to create a moderator/chairperson](https://learn.sessionboard.com/images/kb/46b8d1b7-image-png-Jan-30-2026-03-35-11-6122-PM.png)

2. Within the pop-up window, select the button “Add new contact”.

![Within the pop-up window, select the button “Add new contact”](https://learn.sessionboard.com/images/kb/7ee7a08e-image-png-Jan-30-2026-03-35-27-1135-PM.png)

3. Add all of the contact’s information (i.e. name, email, phone number).
4. Note: First name, Last name, and Email are the only required fields when creating a new contact.
5. Do not forget to click the “Save” button once complete.

💡Sessionboard Tip: For returning contacts, simply search by email or name to add them to your event.

## How to add a moderator/chairperson to a session

[Section titled “How to add a moderator/chairperson to a session”](https://learn.sessionboard.com/contacts/add-a-moderator-chairperson#how-to-add-a-moderatorchairperson-to-a-session)

1. Within the “Sessions” module, select the pencil icon next to the session you wish to edit.

![How to add a moderator/chairperson to a session](https://learn.sessionboard.com/images/kb/e5f6636d-image-png-Jan-30-2026-03-36-09-3458-PM.png)

2. Select the “Participants” tab
3. Navigate to the Chairperson & Moderator fields and select a contact to assign to these roles.

![Navigate to the Chairperson & Moderator fields and select a contact to assign to these roles](https://learn.sessionboard.com/images/kb/f2e94ce0-image-png-Jan-30-2026-03-36-51-2714-PM.png)

4. Do not forget to click the “Save Changes” button once complete.

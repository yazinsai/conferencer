# Event images & dimensions

When creating a new event, using the correct image sizes ensures your event displays properly across all platforms. This article outlines the required images and recommended dimensions for new events in Sessionboard.

Event Images and Dimensions:

| Event Logo | 300 x 300 px | The event logo is displayed within the session submission form, portal, group intake forms, and all emails sent through Sessionboard. |
| --- | --- | --- |
| Event Banner | 1500 x 500 px | The event banner is displayed within the session submission form, group intake forms, and the portal.  Note: Background images should not include text. |

Steps to Add Images:

1. Navigate to the Event Details page within the Settings module.

![Event images & dimensions](https://learn.sessionboard.com/images/kb/e4f91aa2-image-png-Jul-08-2026-05-59-11-1519-PM.png)

2. Click Upload next to the relevant image type.
3. Save your edits once complete.

# Pipeline

The Pipeline tracks and moves prospective speakers through your sourcing workflow — from identification to confirmation for an event (or future consideration). It’s a kanban board where each column is a workflow stage and each card is a prospect.

## Why use it

[Section titled “Why use it”](https://learn.sessionboard.com/speaker-crm/pipeline#why-use-it)

- **Centralized sourcing** — all prospects from all sources in one workflow
- **Stage-based progression** with drag-and-drop
- **Per-card context** — source, stage history, activity log, and team notes
- **Customizable stages** — rename system stages or add your own

## Pipeline + Interest Forms

[Section titled “Pipeline + Interest Forms”](https://learn.sessionboard.com/speaker-crm/pipeline#pipeline--interest-forms)

Interest Forms are how prospects _enter_ the CRM — every submission automatically creates a card. The Pipeline is where teams _work_ prospects: advancing stages, capturing research, adding notes, and assigning to events. You can also enroll any speaker manually with **Enroll**.

## Access

[Section titled “Access”](https://learn.sessionboard.com/speaker-crm/pipeline#access)

Go to your **Organization Dashboard → CRM → Pipeline**. The header includes tabs (All / Speakers), saved views, a **Stages** button, and **\+ Enroll**.

## Default stages

[Section titled “Default stages”](https://learn.sessionboard.com/speaker-crm/pipeline#default-stages)

The Pipeline has 8 system stages, each with a **behavior type** that controls reporting and progression. System stages can be renamed; the behavior stays the same.

| Stage | Behavior type |
| --- | --- |
| Researching | Open |
| Identified | Open |
| Approved | Open |
| Contacted | Open |
| Interested | Open |
| Confirmed | Won |
| Future Fit | Nurture |
| Declined | Lost |

## Enroll prospects

[Section titled “Enroll prospects”](https://learn.sessionboard.com/speaker-crm/pipeline#enroll-prospects)

- **Automatic** — an Interest Form submission creates a card (Identified stage by default), tagged with its source.
- **Manual** — click **\+ Enroll**, pick the prospect, choose a starting stage, and optionally add a **Score (0–100)** and **Rationale**.

## Work a card

[Section titled “Work a card”](https://learn.sessionboard.com/speaker-crm/pipeline#work-a-card)

Open a card for its detail panel:

- **Quick actions** — **Move to** (advance to any stage) and **Assign to event**.
- **Stage History** — every transition with timestamps.
- **Activity** — a filterable feed by **User**, **Agent**, **System**, or **Rule**, with internal **Notes**.
- **Reports** — scouting reports for the prospect.

## Manage stages

[Section titled “Manage stages”](https://learn.sessionboard.com/speaker-crm/pipeline#manage-stages)

Click **Stages** to rename system stages, reorder via drag handles, or **\+ Add custom stage**. Changes apply immediately.

## Assign a prospect to an event

[Section titled “Assign a prospect to an event”](https://learn.sessionboard.com/speaker-crm/pipeline#assign-a-prospect-to-an-event)

Open the card → **Assign to event** → select the event. The prospect links to that event and enters your normal speaker workflow. This is how prospects exit the Pipeline.

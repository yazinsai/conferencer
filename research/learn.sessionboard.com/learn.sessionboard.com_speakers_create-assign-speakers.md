# Create & assign speakers

## Create a speaker contact

[Section titled “Create a speaker contact”](https://learn.sessionboard.com/speakers/create-assign-speakers#create-a-speaker-contact)

Add a contact

In the **Contacts** module, click **Add Contact** in the top right.

Choose 'Add new contact'

Select **Add new contact** in the pop-up.

Enter their information

Add the speaker’s details. **First name**, **last name**, and **email** are required.

Create the contact

Click **Create Contact**.

## Assign a speaker to a session

[Section titled “Assign a speaker to a session”](https://learn.sessionboard.com/speakers/create-assign-speakers#assign-a-speaker-to-a-session)

Open the session

In the **Sessions** module, click the pencil-bolt icon next to the session.

Add them as a participant

On the **Participants** tab, find the **Session Participants** box and search for the speaker’s name.

Save

Click **Save Changes**.

## Reorder speakers

[Section titled “Reorder speakers”](https://learn.sessionboard.com/speakers/create-assign-speakers#reorder-speakers)

Drag and drop speakers by their name on the right side of the screen to set the display order.

## Public vs. hidden speakers

[Section titled “Public vs. hidden speakers”](https://learn.sessionboard.com/speakers/create-assign-speakers#public-vs-hidden-speakers)

All speakers are **public** by default — they appear in embeds and return `is_public = TRUE` in the API. Toggle the icon off to hide a speaker from embeds; they’ll return `is_public = FALSE` via the Open API `Get Sessions` / `Search Sessions` endpoints. Click **Save Changes** to apply.

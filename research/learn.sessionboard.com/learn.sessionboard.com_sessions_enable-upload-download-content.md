# Enable, upload, & download files

Collecting presentations and audio-visual materials for conference sessions can be a time-consuming process. Challenges include transferring large multimedia files, keeping track of constant updates, ensuring content is organized, and finalizing details on a deadline.

Sessionboard now offers an intuitive experience for speakers upload files and communicate with event organizers via the event portal. With a generous file size limit of 1.95 GB per file and built-in tools to manage versions and comments, our solution lets you regain control of the content management process.

* * *

## Enabling files

[Section titled “Enabling files”](https://learn.sessionboard.com/sessions/enable-upload-download-content#enabling-files)

Files can be uploaded to a session by any speaker who has portal access or an event administrator.

To enable file upload…

Navigate to Sessions > Settings > Files

![Enabling Files](https://learn.sessionboard.com/images/kb/693a7675-image-png-Feb-03-2026-09-50-39-7182-PM.png)

Enable File Upload by toggling this feature ON (i.e. GREEN).

![Enable File Upload by toggling this feature ON](https://learn.sessionboard.com/images/kb/77b3a8d3-image-png-Feb-03-2026-09-50-56-5533-PM.png)

This will allow speakers with portal access to upload files to their session(s).

![Enabling files](https://learn.sessionboard.com/images/kb/4f73ffc7-Screenshot-2025-09-30-at-7.15.30-PM.png)

## Uploading files (admin)

[Section titled “Uploading files (admin)”](https://learn.sessionboard.com/sessions/enable-upload-download-content#uploading-files-admin)

Admins can upload content at any time by clicking the pencil icon to the left of a session and then selecting the tab Files.

![Uploading Files](https://learn.sessionboard.com/images/kb/608282b7-image-png-Feb-03-2026-09-52-45-2261-PM.png)

Access the Files tab:

![Access the Files tab](https://learn.sessionboard.com/images/kb/3dcd5f2e-image-png-Feb-03-2026-09-53-15-0785-PM.png)

In Columns, adding the field Files to your view will show which sessions have files uploaded and the total number of files (not including versions).

![In Columns](https://learn.sessionboard.com/images/kb/38f1c1c9-image-png-Feb-03-2026-09-57-39-2046-PM.png)

## File Comments

[Section titled “File Comments”](https://learn.sessionboard.com/sessions/enable-upload-download-content#file-comments)

When a file is uploaded to a session, the session speakers and admin users can add comments to communicate with each other.

To view and send new comments, either click “Expand All” or “Show Comments”.

![File Comments](https://learn.sessionboard.com/images/kb/5a89a4a7-image-png-Feb-03-2026-10-04-38-2160-PM.png)

Each comment will automatically log the name of the user (admin vs. attendee/speaker) who made the comment and the time.

![Each comment will automatically log the name of the user (admin vs. attendee/speaker) who made the comment](https://learn.sessionboard.com/images/kb/2c348448-image-png-Feb-03-2026-10-05-30-6030-PM.png)

## Exporting files

[Section titled “Exporting files”](https://learn.sessionboard.com/sessions/enable-upload-download-content#exporting-files)

Share Files with a Link

Generate a direct link to share files with team members, eliminating the need to download the file.

![Exporting Files](https://learn.sessionboard.com/images/kb/bb626245-image-png-Feb-03-2026-10-06-43-6447-PM.png)

There are two ways to download all of the files that have been shared by the speakers in the form of a zip file:

### Sessions Module

[Section titled “Sessions Module”](https://learn.sessionboard.com/sessions/enable-upload-download-content#sessions-module)

1. Navigate to the Sessions module and select the session(s) you would like to download files for.
2. At the top of your page, select Download Files

![Sessions Module](https://learn.sessionboard.com/images/kb/dc71c464-image-png-Feb-03-2026-10-07-35-7352-PM.png)

3. Within the pop-up window, click the options beside “Group files by” to reorganize how files will appear in folders.
4. Note: The latest version of all session files is included in the exported file. Files can be deselected if they should not be included in the file. Previous versions cannot be included in a file and must be downloaded directly from the session content tab. ​

![Within the pop-up window](https://learn.sessionboard.com/images/kb/7c74c3bd-image-png-Feb-03-2026-10-12-16-3443-PM.png)

![Within the pop-up window](https://learn.sessionboard.com/images/kb/0752af08-image-png-Feb-03-2026-10-12-25-2824-PM.png)

4. Once complete, click Generate Download. You will receive an email once the file is ready to download.

### Files Module

[Section titled “Files Module”](https://learn.sessionboard.com/sessions/enable-upload-download-content#files-module)

1. Within your event, navigate to the Library > Files module.
2. You will see a list of files that have been uploaded, including the session they are associated with. Select the content you would like to download and click Download Files at the top of the page.

![Files Module](https://learn.sessionboard.com/images/kb/7da3ffe8-image-png-Feb-03-2026-10-11-41-5159-PM.png)

3. Within the pop-up window, click the options beside “Group files by” to reorganize how content will appear in folders.
4. Note: The latest version of all session files is included in the exported file. Files can be deselected if they should not be included in the file. Previous versions cannot be included in a file and must be downloaded directly from the session content tab.

![Within the pop-up window](https://learn.sessionboard.com/images/kb/dc880d27-image-png-Feb-03-2026-10-12-09-2548-PM.png)

![Within the pop-up window](https://learn.sessionboard.com/images/kb/b5c0d703-image-png-Feb-03-2026-10-12-28-3039-PM.png)

4. Once complete, click Generate Download. You will receive an email once the file is ready to download.

![Files Module](https://learn.sessionboard.com/images/kb/4d35e696-Screenshot-2025-03-25-at-4.59.56-PM.png)

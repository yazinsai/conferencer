# Create exhibitor groups & contacts

This guide applies only to events that have the Exhibitor module enabled.

When exhibitors complete the intake form, a new exhibitor contact and group are created within your Sessionboard event. Event admins have the ability to add additional contacts to a group and add a new exhibitor group without an intake form being completed.

## Add exhibitor group

[Section titled “Add exhibitor group”](https://learn.sessionboard.com/sponsors-exhibitors/adding-exhibitor-groups-contacts#add-exhibitor-group)

1. Within the Exhibitor module, select the “Add” button at the top right-hand corner of the screen. ​

![Add Exhibitor Group](https://learn.sessionboard.com/images/kb/bb38b148-Screen-Shot-2023-02-09-at-10_20_20-AM-1.png)

2. Select the “Add New Group” button in the pop-up window. ​

![Select the “Add New Group” button in the pop-up window](https://learn.sessionboard.com/images/kb/834a2cf1-Screen-Shot-2023-02-09-at-10_21_51-AM-1.png)

3. Add all of the exhibiting organization’s information (i.e. name, phone number, address).
4. Click “Save” once complete
5. If you would like to add contacts to the group, click the button “Save & Add People” instead.

The fields shown in the Add New Group modal can be customized per event in Settings → Record Settings → Layouts → Group Fields

## Add exhibitor contact

[Section titled “Add exhibitor contact”](https://learn.sessionboard.com/sponsors-exhibitors/adding-exhibitor-groups-contacts#add-exhibitor-contact)

1. Once a group is created, click into the field within the column “Primary Contact”
2. If the group has no contacts, the cell will say “+ Add Contact”. If there are contacts already attached to the exhibitor group and you want to add additional ones, click the cell that says the current contact(s). ​

![Add Exhibitor Contact](https://learn.sessionboard.com/images/kb/2fe28404-Screen-Shot-2023-02-09-at-10_26_41-AM-1.png)

2. Within the pop-up window, click “+ Create a new contact”. ​

![Within the pop-up window, click “+ Create a new contact”](https://learn.sessionboard.com/images/kb/5603b0ce-Screen-Shot-2023-02-09-at-10_28_18-AM-3.png)

3. Add all of the contact’s information. Ensure to list the Record Type as Exhibitors.
4. If the contact is marked as a primary contact, they will be the person to receive any communications the event admin sends from Sessionboard.
5. If the contact is marked to give them login access to the portal, they will not be sent an email from Sessionboard. Once they are given access, the exhibitor will be able to log in to the portal using the portal link. ​

![If the contact is marked to give them login access to the portal](https://learn.sessionboard.com/images/kb/4d237c23-Screen-Shot-2023-02-09-at-10_28_58-AM-1.png)

4. Once complete, click the “Add” button at the bottom of the pop-up window.

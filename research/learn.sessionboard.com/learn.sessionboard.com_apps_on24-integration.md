# ON24

![ON24 logo](https://learn.sessionboard.com/logo/apps/on24-integration.png)

Integrate your ON24 webinars seamlessly with Sessionboard’s Speaker CRM. This one-way integration allows you to import past webinars and speaker data directly into Sessionboard, enabling a comprehensive view of your speaker interactions and history.

* * *

## How to Set Up the ON24 Integration

[Section titled “How to Set Up the ON24 Integration”](https://learn.sessionboard.com/apps/on24-integration#how-to-set-up-the-on24-integration)

### 1\. Navigate to your organization page

[Section titled “1. Navigate to your organization page”](https://learn.sessionboard.com/apps/on24-integration#1-navigate-to-your-organization-page)

- Go to your Organization page in Sessionboard.
- In the top navigation bar, click Import Events.

![1. Navigate to your organization page](https://learn.sessionboard.com/images/kb/bf94dbcb-Screenshot-2025-07-15-at-4.09.56-PM.png)

### 2\. Choose ON24 as your integration source

[Section titled “2. Choose ON24 as your integration source”](https://learn.sessionboard.com/apps/on24-integration#2-choose-on24-as-your-integration-source)

- Select ON24 from the list of available platforms to import Webinars(sessions in Sessionboard) and Speakers

![2. Choose ON24 as your integration source](https://learn.sessionboard.com/images/kb/4cd33f9e-Screenshot-2025-07-15-at-4.10.35-PM.png)

### 3\. Gather Your ON24 API Credentials

[Section titled “3. Gather Your ON24 API Credentials”](https://learn.sessionboard.com/apps/on24-integration#3-gather-your-on24-api-credentials)

To connect ON24, you will need:

- Client ID
- Access Token Secret
- Access Token Key

### 4\. Connect your ON24 account

[Section titled “4. Connect your ON24 account”](https://learn.sessionboard.com/apps/on24-integration#4-connect-your-on24-account)

Click Add New Connection.

![4. Connect your ON24 account](https://learn.sessionboard.com/images/kb/6d7279eb-Screenshot-2025-07-15-at-4.11.52-PM.png)

- Enter your ON24 Access Token Key, Access Token Secret, and Client ID.

![4. Connect your ON24 account](https://learn.sessionboard.com/images/kb/d1b4a180-Screenshot-2025-07-15-at-4.12.56-PM.png)

- Click Connect.

* * *

### 5\. Select events to import

[Section titled “5. Select events to import”](https://learn.sessionboard.com/apps/on24-integration#5-select-events-to-import)

- After connecting, you will see a list of your ON24 webinars.
- Select the events you wish to sync to Sessionboard.
- If you want to connect an ON24 event to an existing Sessionboard event, click the mapping option below the event name.
  - This will add any speakers in ON24 that are not already in Sessionboard to your event.
- Click Next to proceed.

![5. Select events to import](https://learn.sessionboard.com/images/kb/d8513077-Screenshot-2025-07-15-at-4.15.43-PM.png)

### 6\. Data Sync Progress

[Section titled “6. Data Sync Progress”](https://learn.sessionboard.com/apps/on24-integration#6-data-sync-progress)

- A progress bar will display the sync status.

You’ll see:

- Number of Events Synced
- Number of Speakers Imported
- Time Duration of Sync

![6. Data Sync Progress](https://learn.sessionboard.com/images/kb/9c0f90b5-Screenshot-2025-07-15-at-4.16.46-PM.png)

## What Happens After Import

[Section titled “What Happens After Import”](https://learn.sessionboard.com/apps/on24-integration#what-happens-after-import)

### Review synced data in Sessionboard

[Section titled “Review synced data in Sessionboard”](https://learn.sessionboard.com/apps/on24-integration#review-synced-data-in-sessionboard)

- Imported ON24 webinars will appear under the Synced tab in your Sessionboard account.
- Key details available include:
- Event Name
- Event Date & Time
- ON24 Source Indicator (a special icon signifies ON24 imports)

![Review synced data in Sessionboard](https://learn.sessionboard.com/images/kb/4acce385-Screenshot-2025-07-15-at-4.17.20-PM.png)

### How ON24 Data Appears in Sessionboard

[Section titled “How ON24 Data Appears in Sessionboard”](https://learn.sessionboard.com/apps/on24-integration#how-on24-data-appears-in-sessionboard)

- Each ON24 webinar becomes a Session within a Synced Event in Sessionboard.
- Each ON24 speaker has a Contact Profile created in your CRM with the history of the sessions that have spoke at.

### Viewing and managing synced data

[Section titled “Viewing and managing synced data”](https://learn.sessionboard.com/apps/on24-integration#viewing-and-managing-synced-data)

- Synced Events:
- Read-Only Mode: You cannot edit event details, add speakers, or modify sessions within ON24-imported events.
- Speaker Profiles:
- First Name, Last Name, and Email will sync to Sessionboard from ON24
- Full Edit Access: You can enrich speaker profiles by:
- Adding Speakers to existing events/sessions you are managing in Sessionboard
- Updating speaker attributes
- Editing core information

### Managing existing connections

[Section titled “Managing existing connections”](https://learn.sessionboard.com/apps/on24-integration#managing-existing-connections)

- If needed, you can allows delete an existing connection and remove the integration.

![blurred-image](https://learn.sessionboard.com/images/kb/779d0fc5-blurred-image.png)

- The sync to Sessionboard is a one time sync. If you wish to resync an event, please repeat the process and select the event you wish to update/resync.

* * *

One-Way Sync: ON24 data imports into Sessionboard, but changes in Sessionboard do not sync back to ON24.

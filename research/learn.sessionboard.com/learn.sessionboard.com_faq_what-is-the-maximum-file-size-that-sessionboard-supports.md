# Maximum supported file size

Sessionboard supports files as large as 5 GB when using file requests or content upload.

Event admins can set a lower maximum file size for their event under **Settings → Record Settings**. Headshot and logo uploads default to a 5 MB maximum when an image size limit is enabled.

Acceptable file types include:

- Word
- Excel
- PowerPoint
- PDF
- Image
- Video
- Audio

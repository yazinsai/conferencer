# Speaker CRM: add contacts to an event

This guide applies only to organizations that have the Speaker CRM enabled.

Pulling contacts directly from your CRM into an event ensures that all contact data is accessible in the events the contact is associated with. This eliminates the need for manual data entry and reduces the likelihood of errors or duplication.

## How to add a contact to an event

[Section titled “How to add a contact to an event”](https://learn.sessionboard.com/speaker-crm/crm-add-contact-to-events#how-to-add-a-contact-to-an-event)

1. Within the CRM > Directory module, select the contact(s) who should be added to an existing event.

![add contacts to an event: How to add a contact to an event](https://learn.sessionboard.com/images/kb/7b5d9573-image-png-Mar-16-2026-06-30-35-2419-PM.png)

2. At the top of your screen, select ‘+ Add To Event’.
3. Within the pop-up modal, select the event you wish to assign the contact(s) to and click the add to event button.
4. NOTE: Contacts can only be added to one event at a time.

![Within the pop-up modal](https://learn.sessionboard.com/images/kb/f9dba029-image-png-Feb-17-2026-08-24-14-0749-PM.png)

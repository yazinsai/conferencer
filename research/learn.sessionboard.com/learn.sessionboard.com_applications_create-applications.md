# Create applications

Applications can be customized to collect any information you want to store with the person. Examples of use cases are:

- Request to Speak Application
- Awards Application
- Pitch Competition Application

Once submitted, applications can be updated individually or in bulk. You can approve or deny applicants and communicate with them directly from the platform using custom email templates.

​Why would I use Applications instead of the Session Submission Form?

- Not every event begins with a Call for Papers process. Applications allow you to collect information for contacts without requiring them to also submit a session. Applications can also be used more broadly for non-speaker event participants.

## How To Create An Application

[Section titled “How To Create An Application”](https://learn.sessionboard.com/applications/create-applications#how-to-create-an-application)

1. Navigate to the Applications module and select the “Create Form” button.

![How To Create An Application](https://learn.sessionboard.com/images/kb/dd5b3165-image-png-Feb-25-2026-07-22-20-9733-PM.png)

2. Configure your application form by editing the Welcome Screen, Application Information, and Form Settings Pages.

![Configure your application form by editing the Welcome Screen, Application Information](https://learn.sessionboard.com/images/kb/5103848f-image-png-Feb-25-2026-07-22-55-9293-PM.png)

Conditional Logic/Question Rules

Use question rules (conditional logic) to create customizable forms that adjust based on the answers that your users provide to various questions. This allows you to use one form to intake multiple different types of application submissions.

![Use question rules (conditional logic) to create customizable forms that adjust based on the answers](https://learn.sessionboard.com/images/kb/606464e2-image-png-Feb-25-2026-07-24-03-0991-PM.png)

Question rules can only be used on the following field types:

- Textbox
- Dropdown
- Number

## Share the application form

[Section titled “Share the application form”](https://learn.sessionboard.com/applications/create-applications#share-the-application-form)

When it is time to start accepting applications, email the application link or include it on your website. This link can be found using the instructions below.

Navigate to the Applications module and hover over the application form name to select the “Copy Link” button; it’ll automatically copy the application form URL to share with your event community.

![Share The Application Form](https://learn.sessionboard.com/images/kb/7c92803e-image-png-Feb-25-2026-07-39-50-7580-PM.png)

Once an applicant completes the form, they will be redirected to the event portal. Applicants can log back into their portal at any time to view or edit their application.

## View application submissions

[Section titled “View application submissions”](https://learn.sessionboard.com/applications/create-applications#view-application-submissions)

1. Within the Applications module, hover over your application form and select “View Submissions”.

![View Application Submissions](https://learn.sessionboard.com/images/kb/36282d6f-image-png-Feb-25-2026-07-41-42-2602-PM.png)

2. You will have access to a dashboard where you will be able to review all applications received and update their status (i.e. Pending, Accepted Queue, Declined Queue, Declined).

![You will have access to a dashboard where you will be able to review all applications received and update](https://learn.sessionboard.com/images/kb/c8aa505c-image-png-Feb-25-2026-07-48-43-7361-PM.png)

## Frequently Asked Questions

[Section titled “Frequently Asked Questions”](https://learn.sessionboard.com/applications/create-applications#frequently-asked-questions)

1. Do applicants have access to the portal?
2. Yes, applicants will be directed to the portal once they have completed filling out their application.
3. Can I use an integration or open API with applications?
4. No — applications are managed inside Sessionboard.
5. Can I create an evaluation plan for applications?
6. No. Evaluation plans run on sessions and submissions; review applications from the applications dashboard.

# Getting started with awards

Sessionboard Awards is an add-on for creating and managing **awards, grants, or scholarship** programs.

## Where to find Awards

[Section titled “Where to find Awards”](https://learn.sessionboard.com/awards/getting-started#where-to-find-awards)

On your **Organization Dashboard**, go to **Programs → Awards**. The Awards hub shows all programs with stats on submissions, fees, active reviewers, and pending decisions. You can run multiple programs at once.

## Create a program

[Section titled “Create a program”](https://learn.sessionboard.com/awards/getting-started#create-a-program)

Click **\+ New Program** to launch an eight-step wizard. Programs save automatically and start in **Draft** status.

Identity & nomenclature

Program name, **type** (Awards / Grants / Scholarships — sets default terminology), description, and **dynamic labels** (e.g., “Nominator”, “Nomination”, “Nominate”) that cascade through forms, portals, and emails.

Categories

Hierarchical taxonomy up to two nesting levels, each with a name, instructions, drag-and-drop ordering, and linked pricing/reviewer rules.

Form builder

Sections (category selection, submitter info, nomination details, questions), standard and custom fields, field options (labels, help text, required, conditional logic), and form rules (combined character/word limits).

Pricing

Payment timing (free or on submission), gateway, base fee, pricing rules (category or early-bird), VAT rules, and promo codes. Free programs can skip this.

Rounds

A default _Submissions and Review_ round is created. Round types: **Submission + Review** (accept while reviewing) or **Review Only** (finalist/secondary stages).

Winners

Create winner tags from presets (Gold, Silver, Honorable Mention, Finalist…) or custom. Editable after launch.

Managers

Assign Program Managers (co-admins with full access) from existing admins or by email invite.

Notifications

Configure automated emails for submitters, reviewers, and admins. Click **Launch Program** to finish (creates it in Draft).

## Program lifecycle

[Section titled “Program lifecycle”](https://learn.sessionboard.com/awards/getting-started#program-lifecycle)

| Status | Meaning |
| --- | --- |
| **Draft** | Created but inactive; no submissions. Use for setup and testing. |
| **Open** | Actively accepting submissions via your site or a direct link. |
| **Archived** | Inactive with data preserved; no new submissions. |

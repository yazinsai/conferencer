# Portal settings

Adjust your Portal settings (i.e. background color, button colors, typography) to reflect the branding of your organization and event.To locate your portal settings, navigate to Settings > Portals

## Login Page

[Section titled “Login Page”](https://learn.sessionboard.com/settings/portal-settings#login-page)

![Login Page](https://learn.sessionboard.com/images/kb/db37f89d-Screenshot-2024-05-08-at-4_08_34-PM-1.png)

Within Login Page, the following areas can be set:

- Logo Image + Alt-Text (100w x 100h)
- Background Image + Alt-Text (1500w x 400h)
- Button Color
- Button Text Color
- Background Color
- Welcome Message Font, Size, and Color
- Login Message

![Welcome Message Font, Size, and Color](https://learn.sessionboard.com/images/kb/78fc5eb7-image-png-Jul-08-2026-05-52-25-6875-PM.png)

## Appearance (Home Page)

[Section titled “Appearance (Home Page)”](https://learn.sessionboard.com/settings/portal-settings#appearance-home-page)

![Appearance (Home Page)](https://learn.sessionboard.com/images/kb/0858d47b-Screenshot-2025-10-09-at-2.41.20-PM.png)

Within the Home Page, the following areas can be set:

- Logo Image + Alt-Text (100w x 100h)
- Background Image + Alt-Text
- Portals (Legacy): 1500w x 200h
- Portals (Pro): 1920w x 200h
- Make background image full width
- Background Color
- Accent color

# Media library

Media is where every recording lives — uploads, imports from your webinar platforms, and sessions captured with Live Transcribe. Each item gets a transcript, AI chapters, suggested clips, and quotes, all attributed to the speakers who appear in it.

## The tabs

[Section titled “The tabs”](https://learn.sessionboard.com/marketing/media-library#the-tabs)

- **Library** — everything you’ve ingested
- **Discover** — pull recordings from connected platforms
- **Quotes** — the [quote library](https://learn.sessionboard.com/marketing/quotes)
- **Clips** — the [clip library](https://learn.sessionboard.com/marketing/clips)
- **Import** — upload files or paste a URL
- **History** — the status of every import

At the organization level you get your whole corpus across events; inside an event it’s filtered to that event.

## Import recordings

[Section titled “Import recordings”](https://learn.sessionboard.com/marketing/media-library#import-recordings)

### Upload files

[Section titled “Upload files”](https://learn.sessionboard.com/marketing/media-library#upload-files)

Go to **Media → Import** and drag files in, or use **Choose files** or **Choose folder**.

- Video and audio up to **50 GB** per file
- MP4, MOV, MKV, WEBM, M4V, AVI, MP3, M4A, WAV, AAC, FLAC, OGG
- SRT and VTT caption files
- Recordings up to about six hours

Uploads keep running in the bar at the bottom while you work elsewhere in Sessionboard.

### Import from a URL

[Section titled “Import from a URL”](https://learn.sessionboard.com/marketing/media-library#import-from-a-url)

Paste a YouTube or Vimeo URL on the same tab. Vimeo passwords are accepted for the import and aren’t stored. Importing the same URL twice won’t create a duplicate.

### Discover from connected platforms

[Section titled “Discover from connected platforms”](https://learn.sessionboard.com/marketing/media-library#discover-from-connected-platforms)

**Discover** scans platforms you’ve connected under Apps — Zoom, Goldcast, ON24, BigMarker, Cvent, Google Drive, Dropbox, YouTube, Vimeo, and Descript — and lets you select what to bring in. Progress shows under **History**.

## What happens after import

[Section titled “What happens after import”](https://learn.sessionboard.com/marketing/media-library#what-happens-after-import)

Sessionboard extracts the audio, transcribes it with speaker diarization, and adds the result to your searchable corpus. Once the transcript is ready the item opens with a player, an editable transcript, and tools for chapters, clips, and quotes.

Speakers are matched to your contacts automatically, which is what makes content attributable per speaker across events.

## Work with a recording

[Section titled “Work with a recording”](https://learn.sessionboard.com/marketing/media-library#work-with-a-recording)

Open any item from the Library, or a captured session from **Transcribe → Overview**.

- **Chapters** — click **Generate** to segment the recording, or **Regenerate** to redo it
- **Find quotes** — pull quotable lines into your [Quotes library](https://learn.sessionboard.com/marketing/quotes)
- **Suggested clips** — generate clip suggestions, then export the ones you want
- **Transcript** — correct text and tag speakers

## FAQ

[Section titled “FAQ”](https://learn.sessionboard.com/marketing/media-library#faq)

How long does processing take?

It depends on length and queue. Upload is usually the slow part — a large file can run an hour or more. Transcription follows automatically once the upload finishes.

Why is my YouTube import failing?

YouTube sometimes blocks automated downloads from data-centre addresses. Upload the file directly instead.

Can I import captions I already have?

Yes, SRT and VTT files are accepted alongside audio and video.

My library is empty but I've run events.

Media only contains what’s been ingested. Sessions captured before Live Transcribe was enabled won’t appear — import those recordings under **Import**.

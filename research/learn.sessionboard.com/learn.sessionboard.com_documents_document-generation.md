# Create documents

Document creation lives in the **Print** module (previously called Documents) and allows you to create personalized documents using data from your event speakers, sessions, sponsors, and exhibitors. This feature streamlines the process of producing standardized documents, saving your team valuable time and ensuring consistency.

* * *

## Example Documents You Can Create:

[Section titled “Example Documents You Can Create:”](https://learn.sessionboard.com/documents/document-generation#example-documents-you-can-create)

- Session Outline
- Session Run of Show
- Speakers
  - Speaker Bio & Headshot Summary

## How to Create a Document

[Section titled “How to Create a Document”](https://learn.sessionboard.com/documents/document-generation#how-to-create-a-document)

From your left-hand menu, access the Library module to open the dropdown, and select Documents. Tap the + Add Template button on the right-hand side to start a new document.

## Document Editor

[Section titled “Document Editor”](https://learn.sessionboard.com/documents/document-generation#document-editor)

The Document Editor in Sessionboard allows event teams to quickly generate personalized documents by inserting merge fields that dynamically pull in session, speaker, sponsor, and exhibitor information.

These merge fields can be used to automatically populate details such as names, titles, session times, locations, bios, and more, saving time and ensuring accuracy across communications. If there is no data for a record, the record will not be skipped.

![Document Editor](https://learn.sessionboard.com/images/kb/1326d106-Screenshot-2025-04-23-at-8.11.57-PM.png)

❗️IMPORTANT NOTE❗️: Ensure to save your document before previewing it so that you do not lose the edits you have made.

![Document Editor](https://learn.sessionboard.com/images/kb/7c041921-Screenshot-2025-04-23-at-8.27.20-PM.png)

### Include Related Fields

[Section titled “Include Related Fields”](https://learn.sessionboard.com/documents/document-generation#include-related-fields)

To include related entries (e.g., speaker name, job title, company, and biography), users can insert a Related Fields Table, which will generate a structured table of linked data.

![Include Related Fields](https://learn.sessionboard.com/images/kb/bdb948b6-Screenshot-2025-04-23-at-8.18.23-PM.png)

Related fields will be inserted as a table view within your document.

![Include Related Fields](https://learn.sessionboard.com/images/kb/088a22a4-Screenshot-2025-04-23-at-8.19.49-PM.png)

## Publish (export) your document

[Section titled “Publish (export) your document”](https://learn.sessionboard.com/documents/document-generation#publish-export-your-document)

Once you have completed editing your document and you are ready to export, select the blue Save & Next button at the top right-hand corner of your screen to export your created document.

![Publish (export) your document](https://learn.sessionboard.com/images/kb/b6b95c3b-Screenshot-2025-04-23-at-9.12.16-PM.png)

![Publish (export) your document](https://learn.sessionboard.com/images/kb/ec8e0266-Screenshot-2025-04-22-at-7.58.31-PM.png)

| The Preferences page will allow you to set your export preferences.  Checking the box Save as session content will attach the document as a file to each associated session record.  When you are ready to export the document, select the blue Publish button at the bottom of the screen. |  |

# Understanding a portal task

Tasks are the action items your event team assigns to you in the portal. Each task in your task list shows the same set of details.

![A portal task row labelled with task name, required marker, description, due date, and status](https://learn.sessionboard.com/images/kb/d7bd29d4-Screenshot-2025-02-10-at-6-46-46-AM-png.png)

- **Task name** — what you’re being asked to do (for example, “Read T&C”).
- **Required** — a red asterisk means the task is required.
- **Task description** — short instructions from your event team.
- **Task due date** — the date and time the task is due, in the event’s time zone.
- **Task status** — Incomplete or Complete.

Click a task to open the full task view.

![The expanded task view showing details, description, an external link button, and the Mark as Complete button](https://learn.sessionboard.com/images/kb/d221e6c4-Screenshot-2025-02-10-at-6-51-35-AM-png.png)

In the full task view you can see the due date and whether the deadline is still **Open**, read the full description, and use **Open Link** if your event team attached an external link to complete the task. When you’re finished, click **Mark as Complete**. Click **Done** to leave the task view without changing the status.

# Collect Documents/File requests

A file request is a specific type of task that requires the contact/group to upload a document, image, or other file type.

![Collect Documents/File requests](https://learn.sessionboard.com/images/kb/31bee376-Screenshot-2025-10-09-at-2.55.07-PM.png)

📁 File Request Examples:

- Upload Signed Speaker Agreement
- Upload Sponsor/Exhibitor Ad
- Upload Commercial Video

❗️Need to collect Headshots? We recommend using the field Headshot within a Portal Form to request headshots.

❗️Need to collect presentations & handouts? For session assets, we recommend utilizing Files so that you can download all presentations as one zip file.

- Create a File Request
- Assign a File Request to a Portal
- View File Request Completion Status Per Contact/Group
- View & Approve File Request Results
- Export Submitted Files
- File Request Messages

## Create a file request

[Section titled “Create a file request”](https://learn.sessionboard.com/portals/collect-documents#create-a-file-request)

Navigate to Portals on the navigation panel and select “File Requests”.

![Create a File Request](https://learn.sessionboard.com/images/kb/5a7b336f-image-png-Jul-08-2026-09-42-47-9712-PM.png)

Select the “Add File Request” button and complete the following fields:

- Title: This is the name that the task will be listed as within the portal
- Type:
  - Contacts = Speakers or Contacts
  - Groups = Sponsors or Exhibitors
  - Submissions = Sessions
- Instructions: Provide additional helpful instructions on what is needed to submit the requested file.
- Include sample file(s) with this request: By providing a sample file, the portal user may download it to understand what is needed of them.

Once complete, click the “Create File Request” button at the bottom of the pop-up module.

![Once complete, click the “Create File Request” button at the bottom of the pop-up module](https://learn.sessionboard.com/images/kb/dbf5e1c1-image-png-Jul-08-2026-09-43-21-4277-PM.png)

📣 File Requests can only accept one file and may not exceed 1.95 GB when uploaded by the portal user.

## Assign a file request

[Section titled “Assign a file request”](https://learn.sessionboard.com/portals/collect-documents#assign-a-file-request)

Now that you have added your file request, it is time to assign it to the respective portal.

![Assign A File Request](https://learn.sessionboard.com/images/kb/af835400-image-png-Jul-08-2026-09-44-07-6990-PM.png)

2. Within the File Requests widget, select the Add button to open a pop-up module. This will show any file requests you have created to select and assign to your portal.

![Within the File Requests widget, select the Add button to open a pop-up module](https://learn.sessionboard.com/images/kb/436145d1-image-png-Feb-18-2026-08-07-35-9241-PM.png)

3. Once the tasks have been assigned, you can edit additional settings by selecting the pencil under “Actions”.

![Once the tasks have been assigned, you can edit additional settings by selecting the pencil under “Actions”](https://learn.sessionboard.com/images/kb/789cec4f-image-png-Feb-18-2026-08-08-13-3476-PM.png)

1. Alias: Adjust the name of what the task will be listed as in the portal
2. Required: Tasks can be marked as required by toggling ON this button. This action can also be done from the portal’s main menu.
3. Due Date: Assign a due date to each task that the portal user can track.
4. Extended Due Date: Allow task completion beyond the regular due date.

![Extended Due Date](https://learn.sessionboard.com/images/kb/c584bebb-image-png-Feb-18-2026-08-10-25-2467-PM.png)

5. Make Completed Tasks View-Only: Tasks will be set as closed after they are completed. This will not allow contacts/groups to change their task to “Incomplete” after it is completed.
6. Assign By Filter (Session Tasks Only): Apply a filter to a session task so that that task is only visible for sessions that match the filter(s) applied. Note: A maximum of three (3) filters can be applied to a session task.
   - EXAMPLE: Track is Leadership > contacts/groups who are associated with a session, and the session track is Leadership, will see this task.

![EXAMPLE: Track is Leadership > contacts/groups who are associated with a session](https://learn.sessionboard.com/images/kb/0ee5f32d-image-png-Feb-17-2026-10-16-54-3269-PM.png)

Once complete, ensure to click the Update button in the bottom right-hand corner.

## Reviewing & approving files

[Section titled “Reviewing & approving files”](https://learn.sessionboard.com/portals/collect-documents#reviewing--approving-files)

When a portal user submits a file, it will be noted as “Pending Feedback” within their portal with an orange circle next to the task name. This allows for an event admin to review the file that was submitted before it is approved, allowing the portal user to resubmit if needed.

![Reviewing & Approving Files](https://learn.sessionboard.com/images/kb/7b09968c-Screen-Shot-2023-02-01-at-11_47_20-AM-1.png)

![When a portal user submits a file](https://learn.sessionboard.com/images/kb/78446763-Screen-Shot-2023-02-01-at-11_47_35-AM-1.png)

Below are the steps an admin will need to take to review the document that was submitted.

1. Navigate to the Portal module and select the tab “File Requests”.
2. Next, select the ellipses to the right of the file request and select View Submissions. ​

![Select the ellipses to the right of the file request and select View Submissions](https://learn.sessionboard.com/images/kb/3fbd9f6c-image-png-Jul-08-2026-09-46-11-5333-PM.png)

3. Select the pencil icon to the left of the contact you want to review a file for.

![Select the pencil icon to the left of the contact you want to review a file for](https://learn.sessionboard.com/images/kb/6dc9b0f6-image-png-Feb-23-2026-11-22-08-3816-PM.png)

Within the pop-up module that appears, you can review the file by hovering on the file name to open it in a new window or download the file by clicking the download icon to the right of the file name.

To approve or deny the file, you can use the green and red icons below the file. You can also click the three vertical dots to the right of the download icon to approve or deny as well.

![To approve or deny the file, you can use the green and red icons below the file](https://learn.sessionboard.com/images/kb/ff23f0f5-image-png-Feb-23-2026-11-23-15-9364-PM.png)

- Green check mark = Approved

![Green check mark = Approved](https://learn.sessionboard.com/images/kb/0660f530-Screen-Shot-2023-02-01-at-12_02_03-PM-1.png)

- Red “x” = Denied
  - NOTE: When a file request submission is denied, a notification is not sent to the contact/group. As a result, we recommend sending a message so that the contact/group is notified (via email) that there are changes that need to be made. When a file request submission is denied, the contact/group is given the ability to submit a new file as a new version.

![Reviewing & approving files](https://learn.sessionboard.com/images/kb/9a850f5f-Screenshot-2025-02-07-at-5.47.49-PM.png)

- ​Revert to Pending: If you have made a mistake and need to revert the file to its pending status, you can do so by clicking the three vertical dots next to the file download icon and clicking “Revert to pending”.

![Revert to Pending](https://learn.sessionboard.com/images/kb/4fa0cee8-undefined-Feb-23-2026-11-50-54-6236-PM.png)

# Create & assign tasks

A task is a general action item within the portal that a user or group must complete by a specified deadline.

![Create & assign tasks](https://learn.sessionboard.com/images/kb/a9226192-Screenshot-2025-10-09-at-2.51.30-PM.png)

✅ Task Examples

- Register for the event
- Reserve your hotel room
- Attend a pre-event call
- Access the event mobile app
- Create a Task
- Assign Task(s) to a Portal
- View Completed Task Results

* * *

## Create a task

[Section titled “Create a task”](https://learn.sessionboard.com/portals/assign-tasks#create-a-task)

1. Navigate to Portals > Tasks.

![Create A Task](https://learn.sessionboard.com/images/kb/a88ef911-image-png-Feb-17-2026-10-08-48-9112-PM.png)

2. After clicking the Add Task button, complete the following fields:

![After clicking the Add Task button, complete the following fields](https://learn.sessionboard.com/images/kb/42f82de6-image-png-Feb-17-2026-10-09-53-2478-PM.png)

01. Task Name: Label the task so the portal user will know what action to complete.
02. Task Type:
03. Contacts = Speakers, Moderators, Chairpersons, Session Submitters, Exhibitor & Sponsor Contacts
04. Groups = Sponsors & Exhibitors Groups
05. Sessions = Sessions
06. Description: By adding a description, you can provide additional information that the portal user may need to complete the task.
07. Enter Description: With this option, the same task description will be visible to all contacts.
08. Use Field: With this option, the admin can select a pre-created contact or session field to show as the task description. The task description will be unique for each contact, showcasing the data for the field selected.
09. Task Link: Include a link to associate with the task (i.e. link to register for the event)
10. Enter Task URL: With this option, the same URL will be associated with this task for all contacts.
11. Use Field: With this option, the admin can select a pre-created field to use as the task URL. The task URL will be unique for each contact, redirecting the contact to their specific link when selected.

- Note: Links should be formatted with the http:// or https:// prefix (Ex: [https://www.sessionboard.com/](https://www.sessionboard.com/))

## Assign task to a portal

[Section titled “Assign task to a portal”](https://learn.sessionboard.com/portals/assign-tasks#assign-task-to-a-portal)

Now that you have created your task, it is time to assign it to the respective portal.

![Assign Task To A Portal](https://learn.sessionboard.com/images/kb/7106993d-image-png-Feb-17-2026-10-11-42-6222-PM.png)

2. Within the Tasks widget, select the Add button to open a pop-up window. This will show any tasks you have created to select and assign to your portal.

![Within the Tasks widget, select the Add button to open a pop-up window](https://learn.sessionboard.com/images/kb/1c652f3b-image-png-Feb-17-2026-10-12-35-7397-PM.png)

3. Once the tasks have been assigned, you can edit additional settings by selecting the pencil under Actions.

![Once the tasks have been assigned, you can edit additional settings by selecting the pencil under Actions](https://learn.sessionboard.com/images/kb/4d5714a8-image-png-Feb-17-2026-10-13-55-1912-PM.png)

1. Alias: Adjust the name of what the task will be listed as in the portal
2. Required: Tasks can be marked as required by toggling ON this button. This action can also be done from the portal’s main menu.
3. Due Date: Assign a due date to each task that the portal user can track and receive notifications on.
4. Extended Due Date: Allow task completion beyond the regular due date.
5. Make Completed Tasks View-Only: Tasks will be set as closed after they are completed. This will not allow contacts/groups to change their task to “Incomplete” after it is completed.
6. Assign By Filter (Session Tasks Only): Apply a filter to a session task so that that task is only visible for sessions that match the filter(s) applied. Note: A maximum of three (3) filters can be applied to a session task.
   - EXAMPLE: Track is Leadership > contacts/groups who are associated with a session, and the session track is Leadership, will see this task.

![EXAMPLE: Track is Leadership > contacts/groups who are associated with a session](https://learn.sessionboard.com/images/kb/0ee5f32d-image-png-Feb-17-2026-10-16-54-3269-PM.png)

Once complete, be sure to click the Update button in the bottom right-hand corner.

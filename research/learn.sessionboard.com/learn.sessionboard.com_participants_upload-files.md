# Upload files & make comments

If **Files** is enabled for your event, you can upload supporting documents that accompany your session and message admins via comments.

## Upload files

[Section titled “Upload files”](https://learn.sessionboard.com/participants/upload-files#upload-files)

Open Submissions

Click **Submissions** at the top of your portal.

Select your session

Choose the session to open its sidebar on the right.

Open Files

Select the **Files** button below the session name.

Add your file

Drag and drop or browse to select the file.

Set type and upload

Adjust the file details, then click **Upload**:

- **File type** — defaults to _Presentation_; change to _Poster_ or _Handout_ to differentiate content.
- **File versioning** — mark a file as a new version of a previous upload. All versions stay accessible in the history.

## Version history

[Section titled “Version history”](https://learn.sessionboard.com/participants/upload-files#version-history)

Select **History** or **Expand All** to see all versions of a file and download them for cross-reference.

## Comments

[Section titled “Comments”](https://learn.sessionboard.com/participants/upload-files#comments)

Add and view comments on your session content to communicate with event admins directly. Click **Expand All** or **Comment** to view and send comments.

# Create and delete custom fields

## Create a field

[Section titled “Create a field”](https://learn.sessionboard.com/faq/how-to-create-and-delete-custom-fields#create-a-field)

![Create A Field](https://learn.sessionboard.com/images/kb/286008dd-image-png-Jan-30-2026-07-50-10-7164-PM.png)

2. Click the + Add Field button in the top-right corner.

![Click the + Add Field button in the top-right corner](https://learn.sessionboard.com/images/kb/37280833-image-png-Jan-30-2026-07-54-13-1332-PM.png)

3. Within the pop-up modal, define the details of your new field by adding a field name and selecting the field type (i.e. dropdown, file, text, checkbox) from the dropdown menu.

![Within the pop-up modal](https://learn.sessionboard.com/images/kb/9dcbf5ab-image-png-Jan-30-2026-07-55-33-9500-PM.png)

4. Once you’ve completed all the details, click ‘Save Changes’ to add your new field. The custom field will now appear in the list of fields under the selected category and is ready to use. ​

## Delete a field

[Section titled “Delete a field”](https://learn.sessionboard.com/faq/how-to-create-and-delete-custom-fields#delete-a-field)

To delete a field once created, navigate to the Library > Fields module and search for the field you would like to delete.

![Delete A Field](https://learn.sessionboard.com/images/kb/d96cc2e0-image-png-Jan-30-2026-07-56-34-8689-PM.png)

Once the custom field has been located, select Delete within the Actions column.

![Once the custom field has been located, select Delete within the Actions column](https://learn.sessionboard.com/images/kb/0909a755-image-png-Jan-30-2026-07-57-22-7392-PM.png)

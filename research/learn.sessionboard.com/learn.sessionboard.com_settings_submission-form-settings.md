# Submission form settings

Adjust your Session Submission Form settings (i.e. background color, button colors, typography) to reflect the branding of your organization and event.To locate your submission form settings, navigate to Settings > Submission Forms

![Submission form settings](https://learn.sessionboard.com/images/kb/ed621a1c-image-png-Feb-02-2026-08-58-48-3083-PM.png)

* * *

## Appearance

[Section titled “Appearance”](https://learn.sessionboard.com/settings/submission-form-settings#appearance)

![Appearance](https://learn.sessionboard.com/images/kb/0d5db07e-Submission-Form-4--1.png)

Within Appearance, the following areas can be set:

- Logo Image + Alt-Text
- Background Image + Alt-Text
- Background Color
- Primary Button Color + Text Color
- Secondary Button Color + Text Color

## Typography

[Section titled “Typography”](https://learn.sessionboard.com/settings/submission-form-settings#typography)

![Typography](https://learn.sessionboard.com/images/kb/5d3e5cbb-Submission-Form-5--1.png)

Within Typography, the following areas can be set:

- System Font
- Form Title Font Size + Color
- Section Header Font Size + Color
- Section Description Font Size + Color
- Question Labels Font Size + Color

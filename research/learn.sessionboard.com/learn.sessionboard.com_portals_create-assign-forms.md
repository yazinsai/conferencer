## Create a form

[Section titled “Create a form”](https://learn.sessionboard.com/portals/create-assign-forms#create-a-form)

Navigate the Portals module and select Forms.

![Create A Form](https://learn.sessionboard.com/images/kb/031126dc-image-png-Jul-07-2026-04-56-45-8591-PM.png)

Select the Add Form button and add the form’s title, as well as select whether the form will be assigned to individuals, groups, or sessions. Once complete, select the Create button.

- Contacts = Speakers, Moderators, Chairpersons, Session Submitters, Exhibitor & Sponsor Contacts
- Groups = Sponsors & Exhibitors Groups
- Sessions = Sessions

Edit the portal form’s three pages: Form Set Up, Form Questions, and Form Settings.

### Form Setup

[Section titled “Form Setup”](https://learn.sessionboard.com/portals/create-assign-forms#form-setup)

- Internal Form Name: Internal name only visible to back-end users
- External Form Title: External Title that will be visible to contacts/groups within the portal
- Page Heading: Form header displayed at the top

![Form Setup](https://learn.sessionboard.com/images/kb/e4f9b75b-image-png-Jul-07-2026-04-57-37-2639-PM.png)

### Form Questions

[Section titled “Form Questions”](https://learn.sessionboard.com/portals/create-assign-forms#form-questions)

Collect information about the individual or group by adding a section title, description/instructions, and form questions.

To add a question, use the + Add Field button. You can search for existing questions or create a custom question.

![Form Questions](https://learn.sessionboard.com/images/kb/4110ed7a-image-png-Jul-07-2026-04-59-29-1099-PM.png)

![To add a question, use the + Add Field button](https://learn.sessionboard.com/images/kb/b0554f40-image-png-Jul-07-2026-05-00-05-1378-PM.png)

🤔 Did You Know…

If pre-existing contact, group, or session data is available for questions/fields added to a form (e.g., First Name, Last Name, Company Name, Session Title), the portal user will be able to review and update that data when they open the form.

## Assign forms to a portal

[Section titled “Assign forms to a portal”](https://learn.sessionboard.com/portals/create-assign-forms#assign-forms-to-a-portal)

Now that you have created your form, it is time to assign it to the respective portal.

![Assign Forms To A Portal](https://learn.sessionboard.com/images/kb/51656521-image-png-Jul-07-2026-05-01-59-0518-PM.png)

2. Within the Forms widget, select the Add button to open a pop-up window. This will show any forms you have created to select and assign to your portal.

![Within the Forms widget, select the Add button to open a pop-up window](https://learn.sessionboard.com/images/kb/ed767b0a-image-png-Jul-07-2026-05-02-18-3821-PM.png)

3. Once the form has been assigned, you can edit additional settings by selecting the pencil under Actions.

![Once the form has been assigned, you can edit additional settings by selecting the pencil under Actions](https://learn.sessionboard.com/images/kb/76a9227c-image-png-Jul-07-2026-05-04-15-0633-PM.png)

1. Form Title Alias: Adjust the name of what the form will be listed as in the portal
2. Due Date: Assign a due date to each form that the portal user can track.
3. Extended Due Date: Allow form completion beyond the regular due date.
4. Allow edits: Allow for edits after a form has been submitted.
5. Mark this form as required: Forms can be marked as required by toggling ON this button.
6. Make Completed Tasks View-Only: Forms will be set as closed after they are completed.

g. Assign By Filter (Session Tasks Only): Apply a filter to a session task so that the task is only visible for sessions that match the filter(s) applied.

1. EXAMPLE: Track is Leadership > contacts/groups associated with a session, and the session track is Leadership; will see this task.

![EXAMPLE: Track is Leadership > contacts/groups associated with a session](https://learn.sessionboard.com/images/kb/0ee5f32d-image-png-Feb-17-2026-10-16-54-3269-PM.png)

Once complete, ensure to click the Update button in the bottom right-hand corner.

## Bulk Download Files from File Fields

[Section titled “Bulk Download Files from File Fields”](https://learn.sessionboard.com/portals/create-assign-forms#bulk-download-files-from-file-fields)

If your form includes a file field (e.g., to collect logos, signed agreements, or other uploaded documents), you can download all submitted files in bulk as a single zip file. Sessionboard will bundle the files and email you a download link when the bundle is ready.

1. Within the Contacts (or Speakers, Sessions, Sponsors, or Exhibitors) module, select the contacts/records whose files you want to download using the checkbox next to their name.
2. At the top of the page, select More > Download Files.

![2-2](https://learn.sessionboard.com/images/kb/1e3b6e86-2-2.jpg)

3. In the Download Files modal, check Form file uploads — Files uploaded through portal form file fields. You can also select any other file types you want to include in the same bundle:

- Headshots — Speaker headshots/contact photos
- File requests — Files submitted to document/file requests
- Session files — Files attached to sessions (presentations, handouts, etc.)
- Custom field files — Files stored in custom file fields on records
- Awards files — Files uploaded to awards programs (submissions, supporting docs)
- Speaker contracts — Signed speaker contracts (PDFs)

![Bulk Download Files from File Fields](https://learn.sessionboard.com/images/kb/2adf155a-image-png-Jul-07-2026-05-10-55-5008-PM.png)

4. Click Next. Choose how to organize the files within the zip. The options available will vary depending on the file types you selected in the previous step:

- By submitter — files grouped into folders by each contact’s name
- By field — files grouped into folders by form field name
- By record — files grouped by individual record

![By record — files grouped by individual record](https://learn.sessionboard.com/images/kb/f5a0dffd-image-png-Jun-22-2026-03-01-40-0093-PM.png)

5. Click Next. Review the summary showing the total file count and estimated size.

![The summary showing total file count and estimated download size](https://learn.sessionboard.com/images/kb/dad19be7-image-png-Jun-22-2026-03-03-44-7526-PM.png)

6. Click Generate Download. Once the bundle is ready, an Export details screen will appear showing the file name, size, and number of files included. Click Download zip to save it to your device.

![Click Generate Download](https://learn.sessionboard.com/images/kb/a0c13642-image-png-Jun-22-2026-03-04-16-1552-PM.png)

7. You will also receive an email from Sessionboard with the subject “Your file is ready” containing a Download File link, handy if you close the modal before downloading.

![You will also receive an email from Sessionboard with the subject “Your file is ready” containing a Download](https://learn.sessionboard.com/images/kb/711e3730-image-png-Jun-22-2026-03-16-35-7370-PM.png)

## Frequently Asked Questions

[Section titled “Frequently Asked Questions”](https://learn.sessionboard.com/portals/create-assign-forms#frequently-asked-questions)

Q: Will an event admin receive a notification when a form has been submitted?

- Event admins will not receive an email; however, they can view the results of forms by navigating to Portal > Forms > Click on the ellipses on the form you are working on and clicking the button “View Submissions.”

Q: Is there a limit to the number of forms you can create?

- No, create as many forms as you need!

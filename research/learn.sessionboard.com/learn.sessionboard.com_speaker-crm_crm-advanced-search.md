# Speaker CRM: advanced search

This guide applies only to organizations that have the Speaker CRM enabled.

## Advanced Search

[Section titled “Advanced Search”](https://learn.sessionboard.com/speaker-crm/crm-advanced-search#advanced-search)

Cast a wide net or drill down to find relevant contacts.

Using the search bar, team members can conduct a simple search for contacts using key terms that relate to a field (i.e. Contact Name, Company Name, or Job Title).

![advanced search: Advanced Search](https://learn.sessionboard.com/images/kb/8ab7b29d-image-png-Mar-16-2026-06-11-20-5886-PM.png)

Advanced Search via the Filter button allows users to use a combination of attributes and fields that narrow the contact search down. Ultimately, this can be utilized to create segments.

![Advanced Search via the Filter button allows users to use a combination of attributes and fields that narrow](https://learn.sessionboard.com/images/kb/c0c5ef33-image-png-Feb-24-2026-12-41-39-5293-AM.png)

By selecting the ‘Filter’ button to the right of the search bar within ‘Directory’, the user will be shown a list of fields and attributes grouped into categories for ease of navigation. These categories include Demographics, Relevance, Company, History & Connections, Sessions, and Custom.

![To exit Advanced Search, select the ‘X’ icon to the top right of your view](https://learn.sessionboard.com/images/kb/666db663-image-png-Feb-24-2026-12-42-39-6685-AM.png)

Within each filter (white box), users can select fields and attributes by typing a keyword to search by or selecting a field/attribute from the curated shortlist provided. Next to each field/attribute, users will be able to identify the number of contacts that are associated with them (i.e. CEO (560) > this indicates that there are a total of 560 contacts that have the title of CEO). Each filter acts as an ‘AND’ (i.e. Title = CEO AND Pronouns = She/Her) and each attribute/field within a filter acts as an ‘OR’ (i.e. Tile = CEO OR Chief Resident)

![Within each filter (white box)](https://learn.sessionboard.com/images/kb/14bcd066-image-png-Feb-24-2026-12-43-39-5747-AM.png)

As fields and attributes are selected, users will be able to see the total number of contacts that match the search thus far at the top of the page within the green banner.

![As fields and attributes are selected](https://learn.sessionboard.com/images/kb/aa27770f-image-png-Feb-24-2026-12-44-00-7332-AM.png)

Once attributes and fields have been selected, make sure to click ‘Done’ to view the list of contacts that match the advanced search filtering.

# What access do evaluators have?

**No.** Evaluators have deliberately limited access to an event. Here is how their access compares to an admin’s.

## Admin Event Access

[Section titled “Admin Event Access”](https://learn.sessionboard.com/faq/will-evaluators-have-the-same-access-to-my-event-that-i-do-as-an-admin#admin-event-access)

Admins have full access to the event with the ability to:

- Create and view submission forms
- Create portal tasks, files, and wiki pages
- Send email communications to contacts and speakers
- Create evaluation plans
- Manage the event agenda
- Create custom reports

![Admin Event Access](https://learn.sessionboard.com/images/kb/7ff56299-image-png-Jan-28-2026-07-42-32-9048-PM.png)

## Evaluator Event Access

[Section titled “Evaluator Event Access”](https://learn.sessionboard.com/faq/will-evaluators-have-the-same-access-to-my-event-that-i-do-as-an-admin#evaluator-event-access)

Evaluators only have access to complete evaluation plans assigned to them.

# Automated/system-generated emails

The following are emails that are sent by Sessionboard to your event contacts or event users. Some emails can be customized as well as turned on/off.

All emails sent are sent by [no-reply@sessionboard.com](mailto:no-reply@sessionboard.com) (unless you have a custom domain).

## Complete catalog

[Section titled “Complete catalog”](https://learn.sessionboard.com/communications/automated-emails#complete-catalog)

**Account & sign-in** (always on — these protect account access and cannot be disabled or customized)

| Email | When it’s sent |
| --- | --- |
| Reset password | A user requests a password reset. |
| Two-factor code | A one-time login/verification code. |
| Two-factor reset by admin | A user’s 2FA was reset by an admin. |
| Organization invite (new or existing user) | A user is invited to join an organization. |
| Event invite (new or existing user) | A user is invited to join an event team. |
| Org portal magic link | Passwordless sign-in link for the org portal. |
| Live Transcribe magic link | Passwordless sign-in link for Live Transcribe. |

**Sessions & submission forms**

| Email | When it’s sent |
| --- | --- |
| Submission confirmation | Confirms a submission to the submitter. Body text is editable in the form settings. |
| Submission closing reminder | Sent to submitters with draft submissions five days and one day before the form’s close date (when reminders are enabled on the form). |
| New submission (admin) | Notifies selected admins of a new submission. |
| Submission revised (admin) | Notifies selected admins when a submission is revised. |
| Added to a submission | Notifies a speaker when they’re added to a submission. |
| Invoice receipt | Payment receipt for paid submissions. |

**Intake & application forms**

| Email | When it’s sent |
| --- | --- |
| Intake/application confirmation | Confirms an intake or application submission. |
| New or revised intake/application (admin) | Notifies admins of new or updated submissions. |
| Follow-up form confirmation | Confirms a follow-up form submission. |

**Awards** — awards programs have their own notification suite configured per program: submission confirmation, invoice receipt, deadline reminders (five days and one day before the deadline), winner and non-winner notifications, reviewer invitations, reviewer deadline reminders, and admin notifications for new submissions, updates, and completed reviews. See [Awards notifications & email templates](https://learn.sessionboard.com/awards/awards-notifications-email-templates).

**Portal**

| Email | When it’s sent |
| --- | --- |
| Portal assignment notification | A new task, form, or file request is assigned. Can be turned on/off per portal. |
| Weekly portal summary | Weekly digest of portal tasks, sent Mondays at 7 AM UTC. Can be turned on/off per portal. |
| New message / mentioned in a message | Portal communication messages and @mentions. |

**Evaluations**

| Email | When it’s sent |
| --- | --- |
| Evaluation plan opened | Evaluators are notified their assigned plan is open. |
| Evaluation reminder & weekly summary | Progress reminders for evaluators, sent Mondays at 7 AM UTC when enabled. |

**Files, exports & reports**

| Email | When it’s sent |
| --- | --- |
| Report ready | A report export is ready to download. |
| Session content export ready | A session content export is ready. |
| Scheduled report delivery | An Insights report on a schedule. |
| Document request comment | A contact sent a message on a file request task. |

The most common emails are covered in more detail below.

## New Team Member Invitation

[Section titled “New Team Member Invitation”](https://learn.sessionboard.com/communications/automated-emails#new-team-member-invitation)

- When a new user to added to your event or organization, they are sent an email to inform them that they can now access the event or organization through Sessionboard.
- These emails can not be turned off/disabled.
- NOTE: Imported contacts have the option to not be notified upon import.
- Customization: None

## Weekly Digest Email

[Section titled “Weekly Digest Email”](https://learn.sessionboard.com/communications/automated-emails#weekly-digest-email)

🗒️ NOTE: Contacts will only receive this email IF they have created an account/accessed their portal previously.

![Weekly Digest Email](https://learn.sessionboard.com/images/kb/1288a12d-image-png-Feb-17-2026-10-40-16-7974-PM.png)

- Send a weekly email summary of portal actions, upcoming tasks by the due date, as well as new comments.
- Emails are sent every Monday at 7 AM UTC. The day of the week and time the email is sent can not be changed.
- This can be turned on/off for each portal.
- Customization: None

![Can be turned on/off for each portal](https://learn.sessionboard.com/images/kb/b085d1b4-Screenshot-2023-03-14-at-12_45_18-PM-1--1.png)

| Subject Line: \[Event Name\] Portal Task Summary - <send date>​ex: \[Conference 2024\] Portal Task Summary - January 29th, 2024​ Email Preview: |
| --- |

## ​Evaluation Plan Weekly Reminders

[Section titled “​Evaluation Plan Weekly Reminders”](https://learn.sessionboard.com/communications/automated-emails#evaluation-plan-weekly-reminders)

- When enabled, Evaluators who are assigned a specific evaluation plan will receive an email from Sessionboard on Mondays at 7 AM UTC informing them of their plan progress, as well as the number of submissions that have not been reviewed
- These emails can be turned off/disabled.
- Customization: None

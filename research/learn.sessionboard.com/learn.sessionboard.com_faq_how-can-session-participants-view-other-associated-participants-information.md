# Let participants see each other's details

In some cases, a session participant (such as a moderator) may need to view information about other participants in their session — for example, speaker names, emails, or phone numbers.

## Portal Configuration

[Section titled “Portal Configuration”](https://learn.sessionboard.com/faq/how-can-session-participants-view-other-associated-participants-information#portal-configuration)

1. Navigate to the Portals module and click the ellipses (⋮) to the right of the portal where you want users to view session participant information:

![Portal Configuration](https://learn.sessionboard.com/images/kb/fbf7b59b-image-png-Feb-17-2026-09-50-47-4404-PM.png)

2. Select Edit Settings:

![Select Edit Settings](https://learn.sessionboard.com/images/kb/0b838ea7-image-png-Feb-17-2026-09-51-25-8168-PM.png)

3. Within Step 3 (Configuration), enable the setting Manage Sessions:

![Within Step 3 (Configuration), enable the setting Manage Sessions](https://learn.sessionboard.com/images/kb/6b587e82-image-png-Feb-17-2026-09-52-04-7605-PM.png)

1. This setting allows portal users to view specific fields you choose to expose for session participants.
2. It also enables them to view and, if permitted, edit certain session and participant fields.
3. In the following steps, you’ll learn how to control which fields are visible and whether they are editable or view-only (locked).
4. Click the Next button in the top-right corner to navigate to Page 4 (Appearance):

![Click the Next button in the top-right corner to navigate to Page 4 (Appearance)](https://learn.sessionboard.com/images/kb/2abf44c4-image-png-Feb-17-2026-09-59-56-2392-PM.png)

5. In step 4, you can add all the appearance settings for the portal, including title, welcome, logo & background images:

![In step 4, you can add all the appearance settings for the portal, including title, welcome](https://learn.sessionboard.com/images/kb/83f37ee1-image-png-Feb-23-2026-09-52-40-5506-PM.png)

6. In step 5, select Manage Fields:

![In step 5, select Manage Fields](https://learn.sessionboard.com/images/kb/dd9ca5f8-image-png-Feb-23-2026-09-50-59-9315-PM.png)
For both the Session and Contact sections, use the Show/Hide Fields button to control which fields are visible or hidden.

![For both the Session and Contact sections](https://learn.sessionboard.com/images/kb/277aec51-undefined-Feb-23-2026-09-55-39-1807-PM.png)

7. In the Locked column, click the Lock icon to prevent portal users from editing certain fields.
8. We recommend locking all session and contact participant fields so users can view, but not change, session details or participant information.

![We recommend locking all session and contact participant fields so users can view, but not change](https://learn.sessionboard.com/images/kb/aa1aa4e4-image-png-Feb-23-2026-09-56-14-6188-PM.png)

## Steps to View Participant Information in the Portal

[Section titled “Steps to View Participant Information in the Portal”](https://learn.sessionboard.com/faq/how-can-session-participants-view-other-associated-participants-information#steps-to-view-participant-information-in-the-portal)

1. In the My Sessions widget, select the session for which you want to view participant information.

![Steps to View Participant Information in the Portal](https://learn.sessionboard.com/images/kb/20481ee1-Screenshot-2025-08-08-at-4.00.26-PM.png)

2. A side panel will open, displaying detailed session information. Navigate to the Participants tab. You’ll see a list of all participants associated with the session (e.g., speakers, moderators, chairpersons).

![Steps to View Participant Information in the Portal](https://learn.sessionboard.com/images/kb/84c28e56-Screenshot-2025-08-08-at-3.58.56-PM.png)

3. Click on the contact whose information you want to view.

![Steps to View Participant Information in the Portal](https://learn.sessionboard.com/images/kb/fdb5524d-Screenshot-2025-08-08-at-3.59.20-PM.png)

❗️IMPORTANT INFORMATION:

- If the field Email is exposed for the session participants, the mail icon will display. Selecting the icon will allow the user to view the email address.

![Steps to View Participant Information in the Portal](https://learn.sessionboard.com/images/kb/1d5f1f36-Screenshot-2025-08-08-at-4.04.23-PM.png)

- Users will be able to view session participant tasks. Users will not be able to complete tasks for session participants unless they are assigned as their additional contact.

![Steps to View Participant Information in the Portal](https://learn.sessionboard.com/images/kb/39eefaac-Screenshot-2025-08-08-at-4.05.18-PM.png)

# Print agendas

Print agendas turn the sessions, speakers, and sponsors already in your event into printable documents — program books, daily schedules, session handouts, and more. Content is pulled from your event data, so a document refresh picks up the latest changes rather than needing a manual rewrite.

## Before you begin

[Section titled “Before you begin”](https://learn.sessionboard.com/marketing/print-agendas#before-you-begin)

Make sure your event has:

- Accepted sessions
- Accepted speakers
- Basic event configuration — name, dates, and time zone
- A Brand Kit, recommended so branding is applied automatically

## Open print agendas

[Section titled “Open print agendas”](https://learn.sessionboard.com/marketing/print-agendas#open-print-agendas)

Print agendas are available at the event level. Open your event and go to **Program → Print**.

![The Print module in the event navigation](https://learn.sessionboard.com/images/kb/93ddea3f-image-png-Jul-07-2026-07-32-59-7587-PM.png)

Every agenda and program template previously created for this event is listed here.

![The list of existing documents for an event](https://learn.sessionboard.com/images/kb/f1c88265-image-png-Jun-09-2026-10-00-45-1467-PM.png)

## Create a document

[Section titled “Create a document”](https://learn.sessionboard.com/marketing/print-agendas#create-a-document)

There are two ways to add one.

### Add template

[Section titled “Add template”](https://learn.sessionboard.com/marketing/print-agendas#add-template)

Click **Add Template** to start from a predefined template. This is the right choice for most cases.

![The Add Template button](https://learn.sessionboard.com/images/kb/a0f5f426-image-png-Jul-07-2026-07-24-17-7423-PM.png)

### Copy from another event

[Section titled “Copy from another event”](https://learn.sessionboard.com/marketing/print-agendas#copy-from-another-event)

Click **Copy From** to reuse a template from another event in your organization. This carries over layout, branding, and configuration, which is useful for recurring events or keeping a portfolio consistent.

![Copying a template from another event](https://learn.sessionboard.com/images/kb/116cec78-image-png-Jun-09-2026-10-02-26-1542-PM.png)

## Available templates

[Section titled “Available templates”](https://learn.sessionboard.com/marketing/print-agendas#available-templates)

Six pre-built templates cover the most common needs.

![The template picker](https://learn.sessionboard.com/images/kb/231f82ba-image-png-Jun-09-2026-10-03-22-7372-PM.png)

- **Program Book** — the full schedule, speaker profiles, sponsor information, and event details in one official guide for attendees.
- **Daily Schedule Sheet** — a day-by-day view of sessions, rooms, tracks, and times, good for on-site distribution.
- **Session Handout** — one document per session with the title, description, speaker bio, and supporting materials.
- **Speaker View** — a personalized schedule for an individual speaker, for speaker kits and on-site communication.
- **Awards Program** — nominees, categories, presenters, and ceremony flow for printed awards programs.
- **Sponsorship Guide** — sponsor logos, descriptions, and promotional content, standalone or inside a program book.

## Customize your document

[Section titled “Customize your document”](https://learn.sessionboard.com/marketing/print-agendas#customize-your-document)

Every section can be customized. Open the document editor after choosing a template.

![The document editor](https://learn.sessionboard.com/images/kb/b32b71c4-image-png-Jun-09-2026-10-05-37-9036-PM.png)

- **Cover page** — event name, date, location, and brand imagery. Upload a custom cover image or use your Brand Kit background.
- **Welcome section** — a welcome letter or opening message from the organizer or a keynote sponsor.
- **Speaker pages** — how headshots, biography length, session associations, and social links appear.
- **Sponsor pages** — logos, descriptions, and tiered recognition, pulled automatically from your Sponsors module.
- **Agenda layouts** — how sessions, tracks, rooms, and time slots are arranged. Choose list, grid, or track-based layouts.

## Generate content with AI

[Section titled “Generate content with AI”](https://learn.sessionboard.com/marketing/print-agendas#generate-content-with-ai)

Print agendas can draft and polish document copy for you.

![AI content generation inside the document editor](https://learn.sessionboard.com/images/kb/8da92250-image-png-Jul-07-2026-07-32-59-3444-PM.png)

- **Speaker biographies** — generate or rewrite bios from profile data
- **Session descriptions** — polish or expand abstracts for print
- **Welcome letters** — draft an opening message from event context
- **Section introductions** — intro copy for agenda sections, sponsor tiers, or award categories

Everything AI generates stays editable before you finalize or export.

## Preview before exporting

[Section titled “Preview before exporting”](https://learn.sessionboard.com/marketing/print-agendas#preview-before-exporting)

![Preview mode](https://learn.sessionboard.com/images/kb/28319e5f-image-png-Jun-09-2026-10-08-46-9552-PM.png)

Two modes are available:

- **Preview Mode** — review content and layout in a readable format
- **Print Layout View** — the print-ready format, with page breaks, margins, and true print dimensions

Check Print Layout View before exporting to confirm headers, footers, images, and page breaks land where you expect.

![Print layout view with page breaks](https://learn.sessionboard.com/images/kb/2046c7c2-image-png-Jun-09-2026-10-09-11-0797-PM.png)

## Export

[Section titled “Export”](https://learn.sessionboard.com/marketing/print-agendas#export)

![Export options](https://learn.sessionboard.com/images/kb/6eef0598-image-png-Jul-07-2026-07-34-37-1208-PM.png)

- **PDF** — standard export optimized for A4 or Letter. Right for most documents.
- **Large Book PDF** — for long program books with many pages, large images, or high-resolution branding. Handles professional print production more reliably.
- **Markdown** — exports as a `.md` file for use with AI tools and content systems, so you can repurpose the content elsewhere.

## Share a public link

[Section titled “Share a public link”](https://learn.sessionboard.com/marketing/print-agendas#share-a-public-link)

You can share any document at a public URL instead of sending a download.

![Sharing a document via public link](https://learn.sessionboard.com/images/kb/b54943ba-image-png-Jul-07-2026-07-35-40-6069-PM.png)

Anyone with the link can view it, and it always reflects the latest published version — useful for attendees, speakers, on-site staff, and sponsors.

## Permissions

[Section titled “Permissions”](https://learn.sessionboard.com/marketing/print-agendas#permissions)

Print agendas are available to team members with document access. Go to **Event Team → Permissions**, select the role, and confirm the **Documents** permissions are enabled as needed.

## FAQ

[Section titled “FAQ”](https://learn.sessionboard.com/marketing/print-agendas#faq)

### My Brand Kit isn’t applying to the generated document. What should I check?

[Section titled “My Brand Kit isn’t applying to the generated document. What should I check?”](https://learn.sessionboard.com/marketing/print-agendas#my-brand-kit-isnt-applying-to-the-generated-document-what-should-i-check)

Go to **Settings → Branding** and confirm the Brand Kit has a logo, brand colors, and typography saved. Then regenerate the document from **Program → Print**.

### Session data in my document is outdated. How do I refresh it?

[Section titled “Session data in my document is outdated. How do I refresh it?”](https://learn.sessionboard.com/marketing/print-agendas#session-data-in-my-document-is-outdated-how-do-i-refresh-it)

Open the document in the editor and click **Regenerate**. This pulls the latest session, speaker, and sponsor data from your event.

### What’s the difference between PDF and Large Book PDF?

[Section titled “What’s the difference between PDF and Large Book PDF?”](https://learn.sessionboard.com/marketing/print-agendas#whats-the-difference-between-pdf-and-large-book-pdf)

Standard PDF suits typical page sizes and most documents. Large Book PDF is built for program books with many pages, high-resolution images, or professional print requirements, and handles large files and complex layouts more reliably.

### Can I use the same template across multiple events?

[Section titled “Can I use the same template across multiple events?”](https://learn.sessionboard.com/marketing/print-agendas#can-i-use-the-same-template-across-multiple-events)

Yes. Use **Copy From** when creating a document to import a template from any event in your organization. Layout, branding, and configuration carry over; content is populated from the new event’s data.

### Who can access the public share link?

[Section titled “Who can access the public share link?”](https://learn.sessionboard.com/marketing/print-agendas#who-can-access-the-public-share-link)

Anyone with the link — there is no login requirement. It always shows the latest published version, so your updates are immediately visible.

### Can I export a personalized agenda for each speaker?

[Section titled “Can I export a personalized agenda for each speaker?”](https://learn.sessionboard.com/marketing/print-agendas#can-i-export-a-personalized-agenda-for-each-speaker)

Yes. Use the **Speaker View** template to generate personalized schedules, then export or share them individually.

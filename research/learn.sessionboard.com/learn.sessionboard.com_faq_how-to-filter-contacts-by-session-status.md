# Filter contacts by session status

- Method 1: Using Pre-Set Filters (Speakers, Chairpersons & Moderators)
- Method 2: Manually

## Method 1: Using Pre-Set Filters

[Section titled “Method 1: Using Pre-Set Filters”](https://learn.sessionboard.com/faq/how-to-filter-contacts-by-session-status#method-1-using-pre-set-filters)

Go to the Speakers/Chairpersons/Moderators view, and click one of the pre-set filters at the top:

![Method 1: Using Pre-Set Filters](https://learn.sessionboard.com/images/kb/49c10a8b-image-png-Jan-27-2026-07-21-13-7862-PM.png)

The list instantly narrows to speakers on sessions with that status—no setup needed:

- Session – Accepted
- Session – Pending
- Session – Declined

## Method 2: Manually

[Section titled “Method 2: Manually”](https://learn.sessionboard.com/faq/how-to-filter-contacts-by-session-status#method-2-manually)

### 1) Go to the Contacts view

[Section titled “1) Go to the Contacts view”](https://learn.sessionboard.com/faq/how-to-filter-contacts-by-session-status#1-go-to-the-contacts-view)

1. From your event, open any tab under Contacts, can be ‘All Contacts’, ‘Speakers’, ‘Chairpersons’, ’Moderators, or ‘Session Submitters’.
2. Click Columns.

![1) Go to the Contacts view](https://learn.sessionboard.com/images/kb/da14dbfe-image-png-Jan-27-2026-07-23-53-6356-PM.png)
This opens the field picker for the current view.

### 2) Expose the Session Fields

[Section titled “2) Expose the Session Fields”](https://learn.sessionboard.com/faq/how-to-filter-contacts-by-session-status#2-expose-the-session-fields)

1. In the field picker, check the boxes for the fields you want to use (e.g., \[Session\] Status - Accepted).
2. Click Apply Changes to apply.

![2) Expose the Session Fields](https://learn.sessionboard.com/images/kb/3fe03539-image-png-Feb-17-2026-06-17-14-4716-PM.png)

### 3) Add a filter by session status

[Section titled “3) Add a filter by session status”](https://learn.sessionboard.com/faq/how-to-filter-contacts-by-session-status#3-add-a-filter-by-session-status)

1. In the right sidebar, click Filter:

![3) Add a filter by session status](https://learn.sessionboard.com/images/kb/63787e7c-image-png-Jan-28-2026-07-33-00-6640-PM.png)

2. Click Add Filter:

![3) Add a filter by session status](https://learn.sessionboard.com/images/kb/80ae1bd5-image-png-Jan-28-2026-07-33-32-0251-PM.png)

3. Choose the session field you enabled (e.g., \[Session\] Status - Accepted).
4. Set the condition (e.g., Is checked to include Accepted, or Is not checked to exclude).
5. Click ‘Apply Changes’ to see matching contacts.

![Click ‘Apply Changes’ to see matching contacts](https://learn.sessionboard.com/images/kb/c8d1de18-image-png-Feb-17-2026-06-17-49-8127-PM.png)

To save or rename this view, please check our Module Table Views guide.

### Troubleshooting

[Section titled “Troubleshooting”](https://learn.sessionboard.com/faq/how-to-filter-contacts-by-session-status#troubleshooting)

- I don’t see the \[Session\] Status Fields. Make sure you scroll down till you find Status field; you can try doing CTRL + F on your keyboard to search.
- Filters aren’t changing results. Confirm the correct Session Status field is selected, and the condition is set to Is checked.

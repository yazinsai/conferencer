## Method 2: Manually filtering

[Section titled “Method 2: Manually filtering”](https://learn.sessionboard.com/faq/filtering-contacts-to-view-moderators-and-chairpersons#method-2-manually-filtering)

The Contacts module provides a consolidated list of all individuals associated with your event, including speakers, moderators, and chairpersons.

If you’d like to view a list of only speakers, you can navigate to the Speakers module.

To view a list of moderators and/or chairpersons, follow the instructions below:

1. Navigate to the Contacts module.
2. Select the Columns field to expose the fields Moderator & Chairperson within your table view:

![Method 2: Manually filtering](https://learn.sessionboard.com/images/kb/be073df9-image-png-Jan-30-2026-07-40-16-7224-PM.png)

3. Once complete, select the Apply Changes button to apply the changes.

![Once complete, select the Apply Changes button to apply the changes](https://learn.sessionboard.com/images/kb/e252fed4-image-png-Feb-17-2026-04-43-04-6800-PM.png)

4. Once the appropriate field is added to your table view, filter your contact list by either:

![Once the appropriate field is added to your table view, filter your contact list by either](https://learn.sessionboard.com/images/kb/190be0cb-image-png-Jan-30-2026-07-43-02-1656-PM.png)

1. Moderator is not empty

![Moderator is not empty](https://learn.sessionboard.com/images/kb/066b8faf-image-png-Feb-17-2026-04-35-18-4862-PM.png)
OR
2\. Chairperson is not empty

![Chairperson is not empty](https://learn.sessionboard.com/images/kb/fcb5b63f-image-png-Feb-17-2026-04-35-06-7587-PM.png)

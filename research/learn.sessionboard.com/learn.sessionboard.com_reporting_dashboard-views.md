# Module table views

Creating a view is a great way to personalize the way you see fields based on your current needs. Views can be created and seen by all admins.

* * *

Within your event, navigate to the module you are working from (for this example, we will be looking at the Contacts module).

## Columns

[Section titled “Columns”](https://learn.sessionboard.com/reporting/dashboard-views#columns)

Select “Columns” to add, order, and hide fields that you want to be shown on your dashboard view.

![Columns](https://learn.sessionboard.com/images/kb/588de5fc-image-png-Jul-08-2026-05-37-28-8789-PM.png)

Task Completion Status

To manage task completion for sessions, groups (sponsors/exhibitors), and contacts, add the task to your view.

![To manage task completion for sessions, groups (sponsors/exhibitors), and contacts, add the task to your view](https://learn.sessionboard.com/images/kb/9a63812d-image-png-Feb-24-2026-12-46-24-0942-AM.png)

Once completed, click the “Apply Changes” button.

![Once completed, click the “Apply Changes” button](https://learn.sessionboard.com/images/kb/47253349-image-png-Feb-03-2026-07-42-01-5039-PM.png)

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module.

![Once completed, click the “Apply Changes” button](https://learn.sessionboard.com/images/kb/09d8ce85-image-png-Feb-03-2026-07-45-22-4702-PM.png)

## Filters

[Section titled “Filters”](https://learn.sessionboard.com/reporting/dashboard-views#filters)

In the Contacts and Speakers modules, these fields are available to display but not to filter or sort by:

- \[Session\] Track
- \[Session\] Language
- Sessions

Select “Filter” from the right side of your screen.

![Filters](https://learn.sessionboard.com/images/kb/bb8cc340-image-png-Feb-03-2026-07-48-23-7622-PM.png)

Then click “+ Add Filter” to create a new one:

![Click “+ Add Filter” to create a new one](https://learn.sessionboard.com/images/kb/cb384287-image-png-Feb-03-2026-07-48-59-1003-PM.png)

Within the pop-up modal, select the field that you would like to filter by. Next, you will be able to apply settings to this field to further filter by, such as:

- contains
- does not contain
- is
- is not
- is empty
- is not empty
- starts with
- ends with

![The filter operators available when building a dashboard view](https://learn.sessionboard.com/images/kb/e10b1ffe-image-png-Feb-17-2026-06-15-17-9537-PM.png)

Once complete, do not forget to select “Apply Changes” at the bottom of the pop-up modal.

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module.

![Once complete, do not forget to select “Apply Changes” at the bottom of the pop-up modal](https://learn.sessionboard.com/images/kb/09d8ce85-image-png-Feb-03-2026-07-45-22-4702-PM.png)

## Navigate to a view

[Section titled “Navigate to a view”](https://learn.sessionboard.com/reporting/dashboard-views#navigate-to-a-view)

To select a view to see, select the down arrow next to the grey “View” icon. This will open a pop-up modal that will allow you to select a previously created view to see.

![Navigate To A View](https://learn.sessionboard.com/images/kb/790544de-image-png-Feb-03-2026-08-06-38-9765-PM.png)

[Section titled “Rename A View”](https://learn.sessionboard.com/reporting/dashboard-views#rename-a-view)

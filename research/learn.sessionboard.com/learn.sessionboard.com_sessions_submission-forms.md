# Session submission forms

The session submission form is the first point of contact between submitters/speakers and Sessionboard. It gathers session and speaker information and creates records admins can work with. You can create up to **20** submission forms.

## Build a submission form

[Section titled “Build a submission form”](https://learn.sessionboard.com/sessions/submission-forms#build-a-submission-form)

From the **Sessions** module, select **Forms** to access session submission forms. Sessionboard provides a default form you can customize — click the ellipsis ( **⋯**) and select **Edit** to begin.

## The four editable sections

[Section titled “The four editable sections”](https://learn.sessionboard.com/sessions/submission-forms#the-four-editable-sections)

Welcome screen

Introduces your event and is the first screen users see. Supports a custom welcome message.

Session information

Collects session details via a page title, description/instructions, and custom questions. The **Page Heading** is required and cannot be deleted.

Speaker information

Gathers speaker details. **First Name**, **Last Name**, and **Email** are mandatory and cannot be deleted. Unique contact settings let you allow new information for existing contacts and notify existing contacts when added to a submission.

Form settings

- **Close date** — deadline for new submissions and edits
- **Reminder email** — automated messages five days and one day before closing
- **Admin notifications** — alerts for new submissions and edits
- **Speaker limit** — up to 15 speakers per session
- **Submission limit** — cap on submissions per submitter
- **Confirmation message** — customize the confirmation email
- **Automatic redirect** — send users to the portal after 10 seconds
- **Success page** — tailor post-submission messaging

## Create, edit & manage fields

[Section titled “Create, edit & manage fields”](https://learn.sessionboard.com/sessions/submission-forms#create-edit--manage-fields)

### Create fields

[Section titled “Create fields”](https://learn.sessionboard.com/sessions/submission-forms#create-fields)

Click **Add Field** on the _Session Information_ or _Speaker Information_ page. The Select Fields page shows standard and previously created custom fields. Click **Create New Field** to add and configure a new one.

- **Field description** provides internal context that submitters can’t see.
- **Field level** distinguishes _event_ fields (single event) from _global_ fields (reusable across all events).
- Field names are visible to evaluators if you use [Evaluation Plans](https://learn.sessionboard.com/evaluations/evaluation-plans).

### Edit & manage fields

[Section titled “Edit & manage fields”](https://learn.sessionboard.com/sessions/submission-forms#edit--manage-fields)

Select the ellipsis in the **Actions** column:

- **Customize question** — use a custom label to change how the field appears to submitters, and add help text.
- **Question rules** — apply conditional logic so a question only appears based on previous answers. Available for **Checkbox**, **Dropdown**, and **Number** fields. Create and save all fields before applying rules.

## Layout tools

[Section titled “Layout tools”](https://learn.sessionboard.com/sessions/submission-forms#layout-tools)

Hover between fields and click the blue **+** icon to insert:

- **Section header** — group similar fields (255-character limit).
- **Form divider** — a line/break between fields.
- **Rich text box** — images, hyperlinks, and formatted text.

## Form actions

[Section titled “Form actions”](https://learn.sessionboard.com/sessions/submission-forms#form-actions)

From the ellipsis next to a form: **Edit**, **View Submissions**, **View Draft Submissions**, **View Form**, **Duplicate**, and **Delete**.

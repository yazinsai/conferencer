# Recommended browsers

Sessionboard is compatible with a wide range of browsers and operating systems. While there is no preferred browser, we recommend using the latest three versions of your browser and operating system to ensure the best experience.

## Update your web browsers

[Section titled “Update your web browsers”](https://learn.sessionboard.com/faq/what-is-the-recommended-browser-for-using-sessionboard#update-your-web-browsers)

We recommend keeping your web browser updated to the latest version to ensure websites display and function correctly.

- Google Chrome
- Mozilla Firefox
- Apple Safari
- Microsoft Edge

## Why should I use the latest versions?

[Section titled “Why should I use the latest versions?”](https://learn.sessionboard.com/faq/what-is-the-recommended-browser-for-using-sessionboard#why-should-i-use-the-latest-versions)

Keeping your browser and operating system up-to-date ensures:

- Optimal Performance: Sessionboard runs smoothly without lag or unexpected issues.
- Enhanced Security: Newer versions come with the latest security patches.
- Feature Compatibility: Access all of Sessionboard’s features without limitations.

If you experience any issues or need assistance, feel free to reach out to our support team at [support@sessionboard.com](mailto:support@sessionboard.com).

# Participant acceptance

Participant acceptance lets people confirm or decline their part in a session from their portal, rather than by email. Each participant answers for every role they hold on a submission, so someone who is both a speaker and a moderator confirms each one separately.

## Settings

[Section titled “Settings”](https://learn.sessionboard.com/speakers/speaker-acceptance#settings)

In **Settings → Record Settings**, under **Participant Acceptance**:

| Setting | What it does |
| --- | --- |
| **Enable Participant Acceptance** | Lets participants accept or decline each of their roles on a submission. Everything below appears only once this is on. |
| **Enable Participant Acceptance for Subsessions** | Shows acceptance on subsessions and stand-alone submissions only, not on parent submissions that have children. |
| **Allow Submission Withdrawal** | Lets participants withdraw a submission from the portal acceptance task. Turn it off to hide the **Withdraw** button. |
| **Portal Status Verbiage** | Overrides the status text participants read in the portal. |

### Portal Status Verbiage

[Section titled “Portal Status Verbiage”](https://learn.sessionboard.com/speakers/speaker-acceptance#portal-status-verbiage)

Two labels can be reworded, each up to 60 characters. Leave either blank to keep the default.

| Field | Default |
| --- | --- |
| Invited (awaiting confirmation) | Confirmation Needed |
| Submitted (in review) | _(the built-in review wording)_ |

## Set a participant’s status as an admin

[Section titled “Set a participant’s status as an admin”](https://learn.sessionboard.com/speakers/speaker-acceptance#set-a-participants-status-as-an-admin)

Open the session

In **Sessions → Submissions** (or **Agenda**), click the pencil icon next to a session.

Go to Participants

Open the **Participants** page to see each person’s role.

Set the status

Use the **Status** dropdown to set _Accepted_, _Pending_, or _Declined_.

Save

Click **Save Changes**.

## Confirm participation as a participant

[Section titled “Confirm participation as a participant”](https://learn.sessionboard.com/speakers/speaker-acceptance#confirm-participation-as-a-participant)

In the **My Sessions** widget, a **Confirm** button appears for each accepted session. Selecting it opens a dialog to accept or decline, then **Save**. If withdrawal is enabled, they can also **Withdraw** the submission entirely.

When a submission is withdrawn, it shows in **Sessions → Submissions**. Opening it shows who withdrew it and why, and you can delete the session, set it to **Declined**, or undo the withdrawal from the bottom of the page.

## Control who sees invitations

[Section titled “Control who sees invitations”](https://learn.sessionboard.com/speakers/speaker-acceptance#control-who-sees-invitations)

With acceptance on, you can limit which participants see acceptance invitations in the portal, rather than showing them to everyone at once. This is useful when you want to confirm one track or one role before opening it up.

## How the portal groups sessions

[Section titled “How the portal groups sessions”](https://learn.sessionboard.com/speakers/speaker-acceptance#how-the-portal-groups-sessions)

When acceptance is on, the portal splits a participant’s sessions into sections. You control the grouping and the headings per portal — see [portal participation sections](https://learn.sessionboard.com/portals/portals-101#participation-sections).

## FAQ

[Section titled “FAQ”](https://learn.sessionboard.com/speakers/speaker-acceptance#faq)

Can you create custom participant statuses?

No. The statuses themselves are fixed, but you can reword what the portal calls a pending status using **Portal Status Verbiage**.

Can you assign a status to a moderator or chairperson?

Yes. Acceptance now covers every role a participant holds on a submission, and each role is confirmed separately.

Can the Withdraw button be removed from the portal?

Yes. Turn off **Allow Submission Withdrawal** in Record Settings.

Can participants edit co-presenters?

Yes, if the portal setting **Manage Related Sessions & Participants** is enabled (disabled by default). It also lets them edit session details.

Do only accepted participants sync to native integrations?

Yes — only participants with an _Accepted_ status on an accepted session sync to native [integration partners](https://learn.sessionboard.com/integrations/overview).

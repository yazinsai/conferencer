# Program site

The Program Site is the central hub for your event content: one URL for every program interaction, for submitters, reviewers, and anyone engaging with your event.

## What it centralizes

[Section titled “What it centralizes”](https://learn.sessionboard.com/site/program-site#what-it-centralizes)

- Call for Papers forms
- Submission forms (abstracts or sessions)
- Awards forms
- Interest and pipeline forms
- Reviewer access (evaluation plans and rounds)

Forms open in their native interface in a new window (nothing is recreated), and all submissions aggregate into a single unified view regardless of which form they came from.

## Set it up

[Section titled “Set it up”](https://learn.sessionboard.com/site/program-site#set-it-up)

Open the Program Site

In your event, go to **Program → Site**.

Configure settings

Click **Settings** (top right). Sections include:

- **Site URL** — internal site name and public slug (`https://sites.sessionboard.com/s/[your-slug]`)
- **Landing page & login** — title/subtitle, login methods ( **Standard** email login and/or **SSO**), and branding (logo, gradient colors, Google Font, custom HTML/CSS/JS)
- **Logged-in experience** — welcome title/description, logo, background image, font, and primary accent color
- **Available programs** — choose and reorder which programs appear
- **User information** — required fields (First/Last/Email) plus a custom privacy notice
- **Custom pages** — add nav pages (FAQs, instructions) shown in the header and sidebar

Configure reviewer access

Reviewers get in via a **magic link** from their evaluation plan — no admin account needed. They see assigned plans/rounds, track pending vs. completed reviews, and complete scorecards. Admins control visible metadata and filters (track, level, language, tags).

Share the URL

Share the single Program Site URL with submitters and reviewers — it’s the only link they need.

# Upload & share portal files

Files are static documents or links that users can download and view. These can include programs, contracts, venue maps, and so much more.

![Upload & share portal files](https://learn.sessionboard.com/images/kb/62bf3b22-Screenshot-2025-10-09-at-4.49.30-PM.png)

- Upload a File
- Assing a File

* * *

Before you can assign a file to a portal, you will first need to upload one.

## Upload a file

[Section titled “Upload a file”](https://learn.sessionboard.com/portals/share-files#upload-a-file)

Navigate to the Portals module and select “Files”.

![Upload A File](https://learn.sessionboard.com/images/kb/38053f22-image-png-Feb-25-2026-02-53-45-9532-PM.png)

Select the “Add File” button and complete the following fields:

![The fields to complete after selecting the Add File button](https://learn.sessionboard.com/images/kb/66a3e31a-image-png-Feb-25-2026-02-54-50-1793-PM.png)

1. Upload a file or provide an external link
2. Title: This is how the file name will be listed within the portal
3. Description: The description will be listed on the portal home page below the title as helpful text to the portal user.

Once complete, click the “Add File” button at the bottom of the pop-up module.

## Assign a file

[Section titled “Assign a file”](https://learn.sessionboard.com/portals/share-files#assign-a-file)

Now that you have added your file, it is time to assign it to the respective portal.

Within the Portals module, select the ellipses to the right of the portal you would like to assign the file to and select Edit Tasks.

![Assign A File](https://learn.sessionboard.com/images/kb/829167ab-image-png-Feb-25-2026-02-49-31-1707-PM.png)

Within the Files widget, select the button Add to open a pop-up module. This will show any files you have created to select and assign to your portal.

![Within the Files widget, select the button Add to open a pop-up module](https://learn.sessionboard.com/images/kb/cd9b523a-image-png-Feb-25-2026-02-57-40-8353-PM.png)

From the list of uploaded files, Select them next to the file title to add it to your portal.

![From the list of uploaded files, Select them next to the file title to add it to your portal](https://learn.sessionboard.com/images/kb/1532ed1a-image-png-Feb-25-2026-02-59-45-8392-PM.png)
Once done, click the “Add Selected” button at the bottom right-hand corner of the pop-up module.

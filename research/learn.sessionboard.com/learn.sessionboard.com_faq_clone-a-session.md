# Clone a session

Yes. You can duplicate one or more sessions from the Sessions dashboard.

## Clone a session

[Section titled “Clone a session”](https://learn.sessionboard.com/faq/clone-a-session#clone-a-session)

Select sessions

From the Sessions dashboard, check the box next to the session(s) you want to clone.

Duplicate

In the sub-menu, click **More → Duplicate Sessions**, then confirm **Duplicate**.

Done

Your session is cloned.

## What’s included

[Section titled “What’s included”](https://learn.sessionboard.com/faq/clone-a-session#whats-included)

All session information is copied **except**:

- The cloned session’s status is set to **Pending**.
- Uploaded files are **not** included.

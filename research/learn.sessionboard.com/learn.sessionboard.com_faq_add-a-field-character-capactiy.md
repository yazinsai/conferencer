# Add a character limit to a field

Follow the below steps to set a character limit for a system text or textarea field in Sessionboard:

![Add a character limit to a field](https://learn.sessionboard.com/images/kb/47eef453-image-png-Feb-03-2026-09-13-48-9435-PM.png)

2. Select the ellipsis icon (…) & Edit to the right of the field you would like to apply a character limit.

![Select the ellipsis icon (…) & Edit to the right of the field you would like to apply a character limit](https://learn.sessionboard.com/images/kb/cd5980bb-image-png-Feb-03-2026-09-14-34-3119-PM.png)

3. Within the pop-up module, add your character limit to the field labeled Maximum Length.
4. NOTE: Text fields support up to 255 characters. Textarea fields support up to 5000 characters.

![Within the pop-up module, add your character limit to the field labeled Maximum Length](https://learn.sessionboard.com/images/kb/b1d4f7e2-image-png-Feb-03-2026-09-17-47-2699-PM.png)

4. Select the Save Changes button once complete.

![Select the Save Changes button once complete](https://learn.sessionboard.com/images/kb/444b4042-image-png-Feb-03-2026-09-18-04-2828-PM.png)
